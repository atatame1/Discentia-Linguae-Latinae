## 二、三条识别主线

1. **名词**：看**属格单数**词尾 → 定变格类 → 查对应表。
   `-ae` 第一变格 ｜ `-ī` 第二 ｜ `-is` 第三 ｜ `-ūs` 第四 ｜ `-ēī` 第五
2. **动词**：看**现在时第一人称单数**与**不定式** → 定变位类（-āre/-ēre/-ere/-īre，`-ere` 且 1sg 为 -iō 属混合变位）→ 取四个词干 → 套公式。
3. **形容词/代词**：看**主格单数**形式 → 定类型（-a/-um、-is/-e、-īus 型）→ 查表；代词多为「词干 + 固定词尾」，记住词干即可。

## 三、六格功能速记

| 格 | 拉丁名 | 核心功能 | 常见用法 |
|---|---|---|---|
| 主格 | Nōminātīvus | 主语、表语 | 主语；sum 的表语 |
| 属格 | Genetīvus | 「的」 | 所属、部分（partitive）、价值、罪名、动名词宾语 |
| 与格 | Datīvus | 「给/对」 | 间接宾语、利益/损害、所属与格（mihi est）、施事与格（动形词）、目的 |
| 宾格 | Accūsātīvus | 「受/向」 | 直接宾语、方向（in/ad + acc）、持续时间、空间幅度、感叹 |
| 夺格 | Ablātīvus | 「用/从/在」 | 手段、伴随（cum）、方式、地点（in/sub + abl）、时间点、比较、绝对夺格、分离 |
| 呼格 | Vocātīvus | 呼语 | 第二变格 -e/-ī；其余同主格 |
| 方位格 | Locātīvus | 「在（某地）」 | 城市、小岛、domus/humus/rūs/bellum：domī, humī, rūrī, bellī |

## 四、动词速查：六时态的构干公式

设：**现在词干** = 不定式去 -re；**完成词干** = 1sg 完成时去 -ī；**分词词干** = supine 去 -um。

| 时态 | 主动 | 被动 |
|---|---|---|
| 现在 | 现在词干 + 人称词尾 | 现在词干 + 被动词尾 |
| 未完成 | 现在词干 + **-bā-** + 词尾 | 现在词干 + **-bā-** + 被动词尾 |
| 将来（1/2 变位） | 现在词干 + **-bi/-bo/-bu-** + 词尾 | 同左，被动词尾 |
| 将来（3/4 变位） | 现在词干（+e/i）+ **-am/-ēs/-et…** | 同左，被动词尾 |
| 完成 | 完成词干 + **-ī/-istī/-it…** | PPP + sum 现在时 |
| 过去完成 | 完成词干 + **-erā-** + 词尾 | PPP + eram |
| 将来完成 | 完成词干 + **-eri-** + 词尾 | PPP + erō |

## 五、符号约定

- `ā ē ī ō ū` ：长元音；`ă` 等短音一般不标。
- `( )`：可选项或变体（如 `-ērunt (-ēre)`）。
- `～`：同上。
- `/`：并列形式。
- 「同主格」：呼格、方位格等借用主格形式。
