## 二、三条识别主线

1. **名词**：看**属格单数**词尾 → 定变格类 → 查对应表。
   `-ae` 第一变格 ｜ `-ī` 第二 ｜ `-is` 第三 ｜ `-ūs` 第四 ｜ `-ēī` 第五
2. **动词**：看**现在时第一人称单数**与**不定式** → 定变位类（-āre/-ēre/-ere/-īre，`-ere` 且 1sg 为 -iō 属混合变位）→ 取四个词干 → 套公式。
3. **形容词/代词**：看**主格单数**形式 → 定类型（-a/-um、-is/-e、-īus 型）→ 查表；代词多为「词干 + 固定词尾」，记住词干即可。

## 三、六格功能速记

| 格 | 拉丁名 | 核心功能 | 常见用法 |
|---|---|---|---|
| 主格 | Nōminātīvus | 主语、表语 | 主语；sum 的表语 |
| 属格 | Genetīvus | 「的」 | 所属、部分（partitive）、价值、罪名、动名词宾语 |
| 与格 | Datīvus | 「给/对」 | 间接宾语、利益/损害、所属与格（mihi est）、施事与格（动形词）、目的 |
| 宾格 | Accūsātīvus | 「受/向」 | 直接宾语、方向（in/ad + acc）、持续时间、空间幅度、感叹 |
| 夺格 | Ablātīvus | 「用/从/在」 | 手段、伴随（cum）、方式、地点（in/sub + abl）、时间点、比较、绝对夺格、分离 |
| 呼格 | Vocātīvus | 呼语 | 第二变格 -e/-ī；其余同主格 |
| 方位格 | Locātīvus | 「在（某地）」 | 城市、小岛、domus/humus/rūs/bellum：domī, humī, rūrī, bellī |

## 四、动词速查：六时态的构干公式

设：**现在词干** = 不定式去 -re；**完成词干** = 1sg 完成时去 -ī；**分词词干** = supine 去 -um。

| 时态 | 主动 | 被动 |
|---|---|---|
| 现在 | 现在词干 + 人称词尾 | 现在词干 + 被动词尾 |
| 未完成 | 现在词干 + **-bā-** + 词尾 | 现在词干 + **-bā-** + 被动词尾 |
| 将来（1/2 变位） | 现在词干 + **-bi/-bo/-bu-** + 词尾 | 同左，被动词尾 |
| 将来（3/4 变位） | 现在词干（+e/i）+ **-am/-ēs/-et…** | 同左，被动词尾 |
| 完成 | 完成词干 + **-ī/-istī/-it…** | PPP + sum 现在时 |
| 过去完成 | 完成词干 + **-erā-** + 词尾 | PPP + eram |
| 将来完成 | 完成词干 + **-eri-** + 词尾 | PPP + erō |

## 五、符号约定

- `ā ē ī ō ū` ：长元音；`ă` 等短音一般不标。
- `( )`：可选项或变体（如 `-ērunt (-ēre)`）。
- `～`：同上。
- `/`：并列形式。
- 「同主格」：呼格、方位格等借用主格形式。

## 六、词尾反查表：看到形式，反推它是什么

前面各册都是「从词到形」。但查表时更常见的情形是反过来的：读到一个形式，要判断它是什么格、什么时态。这一节就是为此设的。

> 本表按**带长音**的拼写制作。去掉 macron 之后很多条目会合并（-a / -ā、-us / -ūs、-is / -īs），这正是教学拼写要标长音的实际理由。

### 6.1 名词与形容词

| 词尾 | 可能是 | 怎么定 |
|---|---|---|
| -a | 1 变格 N/V sg；2 变格中性 N·Acc pl（templa）；3 变格中性 N·Acc pl（corpora） | 看 -a 前是 -ā 词干还是辅音词干 |
| -ā | 1 变格 **Abl sg**（aquā） | 长 ā 是 1 变格独有的夺格标记 |
| -ae | 1 变格 G/D sg、N/V pl（aquae） | 单复数看谓语与修饰语 |
| -am | 1 变格 Acc sg（aquam） | 与 3 变格 -em 对立 |
| -ārum | 1 变格 G pl（aquārum） | 只此一种，见到即定 |
| -īs | 1/2 变格 D/Abl pl（aquīs, servīs）；代名形容词 D/Abl pl（illīs） | 与 3/4 变格 -ibus 对立 |
| -ō | 2 变格 D/Abl sg（servō） | 见到 -ō 而元音为长，想 2 变格 |

### 6.3 先分「名词性」还是「动词性」

- **只属名词形容词**：-ārum, -ōrum, -ībus 类, -ibus, -ēbus, -ium, -ia, -ae, -am, -em, -ūs。
- **只属动词**：-bam, -bō, -bit, -eram, -erō, -rem, -ssem, -tūrus, -ndus, -isse, -minī, -ntur。
- **两边都可能是**（先靠句法定位，再定词形）：-a, -ā, -e, -ī, -is, -ō, -t, -it, -es。

## 七、重音规则（长音的用处）

拉丁语重音不靠词义，靠**倒数第二音节的长短**，规则只有三条：

| 情形 | 重音位置 | 例 |
|---|---|---|
| 倒数第二音节**长** | 落在倒数第二音节 | amā́bam（a-mā-bam）、imperā́tor（im-pe-rā-tor） |
| 倒数第二音节**短** | 前移到倒数第三音节 | fḗmina（fē-mi-na）、cōnsílium（cōn-si-li-um） |
| 只有两个音节 | 永远在第一个 | ámō、régit |

**什么算「长」**：

1. **本身长**：带 macron 的元音（amāre 的 ā）。
2. **位置长**：元音后接两个或以上辅音，该音节即为长（puél-la、magís-ter）。
3. **x、z 算双辅音**，后面的音节因此变长。
4. **-qu- 的 u 不算辅音**：réliquus（re-li-quus）的倒数第二音节仍是短音。

> 这就是全书标 macron 的实际收益：只要知道倒数第二音节长短，重音自动确定，不必另记。
