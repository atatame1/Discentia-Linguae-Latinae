# 10 · 虚词：介词、连词、小品词

> 虚词不变格、不变位，却决定三件事：名词用哪个**格**、从句用哪种**语气**、句子是陈述还是疑问。
> 前十册讲「词怎么变」，本册讲「词怎么连」。长句读不懂，多半卡在这里而不是卡在词形。

---

## 1. 介词总表

### 1.1 只带宾格

| 介词 | 核心义 | 例 |
|---|---|---|
| ad | 到、向；为了；大约 | ad urbem 进城；ad pācem 为和平；ad decem mīlia 约一万人 |
| adversus / adversum | 对着、反对 | adversus hostēs 迎敌 |
| ante | 在……之前（空间、时间） | ante portam 门前；ante bellum 战前 |
| apud | 在……处；在……家中；在……著作中 | apud Caesarem 在凯撒处／在凯撒书中 |
| circā / circum | 环绕；大约（时间） | circā urbem 环城；circā vesperum 傍晚前后 |
| cis / citrā | 在……这一边 | cis flūmen 河这边 |
| contrā | 反对；面对 | contrā lēgem 违法 |
| ergā | 对（某人的态度） | benevolēns ergā mē 对我友善 |
| extrā | 在……之外 | extrā mūrōs 墙外 |
| īnfrā | 在……之下 | īnfrā montem 山下 |
| inter | 在……之间；在……期间 | inter nōs 我们之间；inter cēnam 席间 |
| intrā | 在……之内 | intrā mūrōs 墙内 |
| ob | 因为；以……为代价 | ob eam rem 因这件事 |
| penes | 在……权力之内 | penes cōnsulem 在执政官手中 |
| per | 穿过；借、由（中介）；整个……期间 | per silvam 穿林；per lēgātōs 通过使节 |
| post | 在……之后 | post bellum 战后 |
| praeter | 经过；除……之外 | praeter spem 出乎意料 |
| prope | 靠近 | prope urbem 城附近 |
| propter | 因为；靠近 | propter metum 因为恐惧 |
| secundum | 沿着；按照 | secundum nātūram 顺自然 |
| suprā | 在……上方；超过 | suprā terram 地上 |
| trāns | 越过 | trāns mare 渡海 |
| ultrā | 超过 | ultrā modum 过度 |
| versus | 朝向（**后置**） | Rōmam versus 朝罗马 |
| ūsque ad | 直到 | ūsque ad noctem 直到夜里 |

### 1.2 只带夺格

| 介词 | 核心义 | 例 |
|---|---|---|
| ā / ab | 从；被（施事） | ā mīlitibus 被士兵们 |
| absque | 没有（少见） | absque dubiō 无疑 |
| coram | 在……面前 | coram omnibus 当众 |
| cum | 与；带有 | cum amīcīs 与朋友 |
| dē | 从……向下；关于 | dē monte 下山；dē officiīs 论义务 |
| ē / ex | 从……出；自……起；按照 | ex urbe 出城；ex eō diē 自那日起 |
| prae | 在……前；由于；与……相比 | prae timōre 因恐惧 |
| prō | 在……前；为了；代替；作为 | prō patriā 为国；prō cōnsule 代理执政官 |
| sine | 没有 | sine cōnsiliō 无计划 |
| tenus | 直到（**后置**，多带夺格，也可带属格） | genū tenus 直到膝 |

### 1.3 两可：格一换，义就变

| 介词 | + 宾格 | + 夺格 |
|---|---|---|
| **in** | 进入、朝向、反对：in urbem 进城；in hostēs 攻敌 | 在……里、在……上：in urbe 在城里 |
| **sub** | 到……下面；将近：sub mūrum 到墙下；sub noctem 近夜 | 在……下面：sub mūrō 墙下 |
| **super** | 在……上方；超过：super montem 到山上 | 关于：super hāc rē 论此事 |
| **subter** | 到……下面 | 在……下面 |
| **clam** | 暗中（多带宾格） | 暗中（少见） |

> **in 的两个意思就是两个方向**：+ 宾格回答「往哪」，+ 夺格回答「在哪」。这一条能解决介词题的一半。

## 2. 高频介词的义项细分

同一个介词在不同搭配里意思差很远，词典往往只给三四个，读原文时容易误判。

| 介词 | 义项 | 例 |
|---|---|---|
| **ad** | ① 到 ② 为了 ③ 大约 ④ 按照、依照 ⑤ 除……之外 | ad urbem；ad pācem；ad decem mīlia；ad nūtum；ad hoc |
| ab | ① 从 ② 被（施事）③ 自从 ④ 站在……一边 | ab urbe；ā Caesare factum；ab hinc annōs decem；ā populō stāre |
| **cum** | ① 与 ② 带有 ③ 在……情况下 | cum exercitū；cum cūrā；cum silentiō |
| **dē** | ① 从……下 ② 关于 ③ 根据 ④ 部分（of） | dē caelō；dē officiīs；dē sententiā meā；ūnus dē multīs |
| **ex / ē** | ① 出 ② 自……起 ③ 按照 ④ 由……构成 | ex urbe；ex eō diē；ex sententiā；ex aere |
| **per** | ① 穿过 ② 借、由 ③ 整个……期间 ④ 凭（起誓） | per silvam；per lēgātōs；per tōtam noctem；per deōs |
| **prō** | ① 为了 ② 代替、代理 ③ 按照 ④ 当作 | prō patriā；prō cōnsule；prō ratā parte；prō certō habēre |
| **prae** | ① 在……前 ② 由于 ③ 与……相比（多否定句） | prae gaudiō；prae timōre；nihil prae hāc rē |

## 3. 介词短语的位置与写法

- **常规**：介词在名词前，整个短语多在动词前。
- **可插入**：形容词 + 介词 + 名词，是正式文体的常态，不是例外。
  > magnā **cum** laude 带着巨大荣誉｜summā **cum** virtūte 以最高德行｜quā **dē** causā 由于这个原因
- **代词与 cum 连写**，且 cum 后置：
  > mēcum, tēcum, sēcum, nōbīscum, vōbīscum；关系代词 quōcum, quācum, quibuscum
  > 写成 *cum mē 是错的。
- **介词可单独作副词**：ante, post, contrā, suprā, īnfrā, prope, circā, extrā, intrā, ultrā, clam, palam。
  > ante dīxī 我先前说过｜post vēnit 他后来来了
- **介词不引导从句**：postquam、antequam 里的 post/ante 只是构词成分，不是介词。

## 4. 连词（一）：并列

| 关系 | 连词 | 说明 |
|---|---|---|
| 加合 | et, -que, atque / ac | **-que 附在第二个词后**：arma virumque；atque 多用于元音前，ac 多用于辅音前 |
| 加合框架 | et...et, cum...tum, tum...tum | 既……又；不但……而且 |
| 否定加合 | neque / nec, neque...neque | 相当于 et nōn |
| 选择（排斥） | aut, aut...aut | 二者只能其一，「要么……要么」 |
| 选择（不限） | vel, vel...vel, -ve | 「或，随你选」；-ve 亦后附 |
| 选择（换个说法） | sīve / seu, sīve...sīve | 「或曰」 |
| 转折 | sed, at, autem, vērum, tamen, attamen, immō, atquī | **autem 必须后置**（第二位置） |
| 原因 | nam, namque, enim, etenim | **enim、etenim 后置** |
| 推论 | igitur, itaque, ergō, ideō, proptereā, quārē, quāpropter | **igitur 常后置** |

> **-que 的位置**是拉丁语最容易被忽略的细节：*senātus populusque Rōmānus* 是「元老院与罗马人民」，-que 挂在 populus 上，不是 senātus。

## 5. 连词（二）：从属 —— 按「要什么语气」记

从属连词不必逐个背意思，只要记住**它要求陈述式还是虚拟式**，语气一反推，从句类型就定了。

| 从句 | 连词 | 语气 | 例 |
|---|---|---|---|
| 目的 | ut, nē, quō, quī | 虚拟 | *Vēnit ut vidēret.* 他来了是为了看。 |
| 结果 | ut, ut nōn | 虚拟 | *Tam bonus est ut omnēs eum ament.* |
| 时间 | cum, ubi, postquam, antequam, priusquam, dum, dōnec, quoad, simul ac, ut prīmum | 陈述；antequam / priusquam 可虚拟表意图 | *Postquam vēnit, abiit.* |
| 原因 | quod, quia, quoniam, quandō, siquidem, cum | 陈述；quod / cum 用虚拟 = 转述他人理由或主观判断 | *Quod valēs, gaudeō.* |
| 条件 | sī, nisi, sīn, dummodo, modo, etsī, etiamsī, tametsī | 陈述或虚拟（看条件类型） | *Sī valēs, gaudeō.* |
| 让步 | quamquam（只带陈述）；quamvīs, licet, cum 带虚拟；etsī（陈述＝虽然，虚拟＝即使） | 陈述／虚拟 | *Quamvīs dīves sit…* |
| 间接疑问 | 疑问词（quis, quid, cūr, ubi, quandō…） | 虚拟 | *Rogāvit quid faceret.* |
| 间接命令 | ut, nē | 虚拟 | *Imperāvit ut venīret.* |
| 担心 | nē, nē nōn, ut | 虚拟 | *Timeō nē veniat.* |
| 比较 | ut, velut, sīcut, tamquam, quasi, ac sī, ut sī | 陈述或虚拟 | *Fortiter pugnāvit ut leō.* |
| 预防 | quīn, quōminus | 虚拟 | *Nōn prohibuit quīn venīret.* |

> **三个「一语两用」的连词**，全靠语气分辨：
> - **ut** + 陈述 = 「如、当」；+ 虚拟 = 目的或结果
> - **cum** + 陈述 = 「当……时」；+ 虚拟 = 「当／因为／虽然」
> - **quod** + 陈述 = 「因为（事实）」；+ 虚拟 = 「理由是（别人说的）」

## 6. 小品词

### 6.1 疑问

| 形式 | 期待的答案 | 例 |
|---|---|---|
| **-ne**（后附于首词） | 中性，纯提问 | *Vidēn?* 你看见了吗？ |
| **num** | 期待「不」 | *Num vēnit?* 他难道来了？（我看没来） |
| **nōnne** | 期待「是」 | *Nōnne vēnit?* 他不是来了吗？ |
| **an** | ① 双问中的「或者」② 单问中表惊讶「难道」 | *Utrum Rōmam an Athēnās īs?* |
| **utrum...an / -ne...an** | 二选一 | *Rōmamne an Athēnās īs?* |

**回答**：ita / vērō / sānē / certē / etiam（是）｜minimē / nōn（不）。

### 6.2 强调、限定、情态

| 小品词 | 义 | 位置 |
|---|---|---|
| quidem | 确实、至少 | 后置；**nē...quidem** 包住被否定的词：nē puer quidem 连孩子都不 |
| equidem | 我本人（至少） | 常置句首 |
| quoque | 也 | 后置，附于被强调词后 |
| etiam | 也、甚至 | 前置 |
| sānē, profectō, certē | 确实、当然 | 自由 |
| scīlicet, vidēlicet, nempe, quippe | 当然、显然、即 | 多置句首 |
| immō | 不，恰恰相反 | 句首 |
| potius, potissimum | 宁可；尤其 | 自由 |
| modo, tantum, sōlum | 只；modo 亦可作「刚才」 | 自由 |
| saltem | 至少 | 自由 |
| vix | 几乎不 | 自由 |
| paene, fermē / fere | 几乎 | 自由 |
| omnīnō, prorsus | 完全、总之 | 自由 |
| adeō | 到如此程度 | 常位于被修饰词前 |
| tamen | 仍然、然而 | 常在第二位置 |

### 6.3 否定

| 形式 | 用法 |
|---|---|
| **nōn** | 一般否定，否定整个陈述 |
| **haud** | 多修饰形容词、副词（haud dubiē 无疑），少修饰动词 |
| **nē** | 禁止、愿望的否定：nē fēceris 别做 |
| **minimē** | 强烈否定「绝不」，也用于回答「不」 |
| **nē...quidem** | 连……也不（被强调成分夹在中间） |
| **nōn sōlum...sed etiam** | 不但……而且 |
| **neque...neque** | 既不……也不 |
| numquam, nūsquam, nēmō, nihil, nūllus | 从不、无处、无人、无物、无 |

> 拉丁语是**多重否定仍表否定**的语言：*nēmō umquam* 从来没有人、*nihil umquam* 从来没有过什么。不要按英语逻辑把它翻成肯定。

| 词 | 义 |
|---|---|
| ō | 啊、哦（+ 呼格） |
| heu, ēheu | 唉 |
| vae | 糟糕（+ 与格或呼格）：vae victīs! 败者遭殃！ |
| ecce, ēn | 看哪 |
| age / agite | 来吧、干吧 |
| euge | 好极了 |

## 7. 易错点

| # | 坑 | 正解 |
|---|---|---|
| 1 | in 一律译「在」 | + 宾格是「进入」，+ 夺格才是「在」 |
| 2 | sub 一律带夺格 | 表「到……下面」用宾格：sub mūrum |
| 3 | cum mē | 必须 **mēcum**（cum 后置连写） |
| 4 | 介词后面随便接格 | 每个介词只支配固定格，1.1–1.3 三张表是硬规则 |
| 5 | ut 一律译「为了」 | ut + 陈述 = 如／当；+ 虚拟才可能是目的或结果 |
| 6 | cum 一律译「当……时」 | cum + 虚拟还可表「因为」「虽然」 |
| 7 | quod 一律译「因为」 | quod + 虚拟是「理由是（转述）」，不是事实原因 |
| 8 | aut 与 vel 混用 | aut 排斥（二选一），vel 不排斥（随你） |
| 9 | -que 挂在第一个词后 | 挂在**第二个**词后：senātus populusque |
| 10 | enim / autem / igitur 置句首 | 三者都是后置词，常在第二位置 |
| 11 | nē...quidem 分开理解 | 被强调词夹在中间：nē puer quidem = 连孩子都不 |
| 12 | 多重否定当肯定 | 拉丁语多重否定仍为否定 |

## 8. 一页自测

1. *in urbem* 与 *in urbe* 的区别？→ 前者「进城」（宾格，方向），后者「在城里」（夺格，位置）
2. *mēcum* 为什么不能写 *cum mē*？→ cum 与人称代词连写且后置
3. *magnā cum laude* 为什么 cum 在中间？→ 介词可插在形容词与名词之间，正式文体常见
4. *Num vēnit?* 说话人倾向什么答案？→ 倾向「没有来」
5. *Nōnne vēnit?* 呢？→ 倾向「来了」
6. *Timeō nē veniat* 与 *Timeō ut veniat* 的区别？→ 前者怕他来，后者怕他不来
7. *Quamvīs dīves sit* 的 sit 为什么是虚拟式？→ quamvīs 引导让步从句，要求虚拟式
8. *nēmō umquam* 译成「没有人曾经」还是「有人曾经」？→ 前者，多重否定仍为否定
