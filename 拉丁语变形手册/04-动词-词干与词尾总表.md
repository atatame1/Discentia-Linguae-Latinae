# 04 · 动词：词干、变位类与全部词尾

> 拉丁语动词的所有形式都由**四个词干**拼装出来。先定词干，再查词尾，任何形式都能现场合成。

---

## 1. 变位类识别（看 1sg 现在时 + 不定式）

| 变位 | 不定式 | 1sg 现在时 | 例 | 现在词干 | 特征 |
|---|---|---|---|---|---|
| 第一 | -**ā**re | -**ō** | amō, amāre | amā- | 主题元音 ā |
| 第二 | -**ē**re（长 ē） | -**eō** | moneō, monēre | monē- | 主题元音 ē |
| 第三 | -**e**re（短 e） | -**ō** | regō, regere | reg- | 无稳定主题元音 |
| 第三 io（混合） | -**e**re（短 e） | -**iō** | capiō, capere | capi- | 短 e 但 1sg 有 i |
| 第四 | -**ī**re | -**iō** | audiō, audīre | audī- | 主题元音 ī |

> **第二与第三之分**：看不定式的 ē 长短——monēre（长）vs regere（短）。
> **第三与混合之分**：看 1sg——regō vs capiō。教材中 capiō 型常并入第三变位，但变位时要单独处理。

---

## 2. 四个词干

| 词干 | 取得方式 | 用途 |
|---|---|---|
| **现在词干** | 不定式去 -re | 现在、未完成、将来；主动与被动；虚拟式现在/未完成；命令式；现在分词；动名词 |
| **完成词干** | 1sg 完成时去 -ī | 完成、过去完成、将来完成（主动）；虚拟式完成/过去完成（主动） |
| **分词词干（PPP）** | supine 去 -um | 完成被动系统；完成被动分词；将来主动分词（-ūrus）；动形词（-ndus） |
| **supine** | 第四形式 | 目的分词（-tum/-tū） |

### 2.1 五种变位的词干示例

| 动词 | 1sg 现在 | 不定式 | 1sg 完成 | supine | 现在词干 | 完成词干 | PPP |
|---|---|---|---|---|---|---|---|
| amō 爱 | amō | amāre | amāvī | amātum | amā- | amāv- | amāt- |
| moneō 提醒 | moneō | monēre | monuī | monitum | monē- | monu- | monit- |
| regō 统治 | regō | regere | rēxī | rēctum | reg- | rēx- | rēct- |
| capiō 拿 | capiō | capere | cēpī | captum | capi- | cēp- | capt- |
| audiō 听 | audiō | audīre | audīvī | audītum | audī- | audīv- | audīt- |

### 2.2 完成词干的六种来源（配合《拉丁语动词双系统笔记》看）

| 类型 | 例 | 说明 |
|---|---|---|
| -āv- / -ēv- / -īv- | amāvī, dēlēvī, audīvī | 新系统规则型 |
| -uī / -vī | monuī, docuī | 晚出、规则、扩散快 |
| 长元音 | vēnī, vīcī, lēgī | 旧系统 |
| s-完成 | dūxī, scrīpsī, coxī, gessī | 源自 s-aorist |
| 重叠 | dedī, stetī, cecīdī, tetigī | 旧系统 |
| 完全换词干 | ferō → tulī；ferō → lātum | 异干 |

## 3. 体系结构

```
                 ┌─ 现在系统（现在词干）
                 │   现在时、未完成时、将来时
主动/被动都在这 ─┤   虚拟式现在、未完成
                 │   命令式、现在分词、动名词
                 │
                 └─ 完成系统（完成词干 / PPP）
                     完成时、过去完成、将来完成
                     主动：完成词干 + 词尾
                     被动：PPP + esse（现在/未完成/将来）
```

## 5. 六时态构干公式

设现在词干 = S，完成词干 = P，分词词干 = T。

| 时态 | 主动 | 被动 |
|---|---|---|
| 现在 | S + 主动词尾 | S + 被动词尾 |
| 未完成 | S + **-bā-** + 词尾 | S + **-bā-** + 被动词尾 |
| 将来（1/2） | S + **-bō/-bi/-bu-** + 词尾 | S + **-bor/-be/-bi-** + 被动词尾 |
| 将来（3/4） | S（+e/i）+ **-am/-ēs/-et/-ēmus/-ētis/-ent** | S + **-ar/-ēris/-ētur/-ēmur/-ēminī/-entur** |
| 完成 | P + -ī/-istī/-it/-imus/-istis/-ērunt | T + sum（现在时） |
| 过去完成 | P + **-erā-** + 词尾 | T + eram |
| 将来完成 | P + **-eri-** + 词尾 | T + erō |

### 5.1 现在系统各变位的连接元音

| 变位 | 1sg | 2sg | 3sg | 1pl | 2pl | 3pl |
|---|---|---|---|---|---|---|
| 1 amō | amō | amās | amat | amāmus | amātis | amant |
| 2 moneō | moneō | monēs | monet | monēmus | monētis | monent |
| 3 regō | regō | regis | regit | regimus | regitis | regunt |
| 3io capiō | capiō | capis | capit | capimus | capitis | capiunt |
| 4 audiō | audiō | audīs | audit | audīmus | audītis | audiunt |

### 5.2 未完成时（全部变位都用 -bā-）

| 变位 | 1sg | 2sg | 3sg |
|---|---|---|---|
| 1 | amābam | amābās | amābat |
| 2 | monēbam | monēbās | monēbat |
| 3 | regēbam | regēbās | regēbat |
| 3io | capiēbam | capiēbās | capiēbat |
| 4 | audiēbam | audiēbās | audiēbat |

> 注意：3/4 变位的现在词干在 -bā- 前要加 **-ē-**（reg- → regē-, audi- → audiē-）。

### 5.3 将来时（两套）

**第一/二变位：-bō / -bi- / -bu-**

| | 1 | 2 |
|---|---|---|
| 1sg | amābō | monēbō |
| 2sg | amābis | monēbis |
| 3sg | amābit | monēbit |
| 1pl | amābimus | monēbimus |
| 2pl | amābitis | monēbitis |
| 3pl | amābunt | monēbunt |

**第三/四变位：-am / -ēs / -et …**

| | 3 regō | 3io capiō | 4 audiō |
|---|---|---|---|
| 1sg | regam | capiam | audiam |
| 2sg | regēs | capiēs | audiēs |
| 3sg | reget | capiet | audiet |
| 1pl | regēmus | capiēmus | audiēmus |
| 2pl | regētis | capiētis | audiētis |
| 3pl | regent | capient | audient |

### 5.4 被动将来时

| 变位 | 1sg | 2sg | 3sg |
|---|---|---|---|
| 1 | amābor | amāberis | amābitur |
| 2 | monēbor | monēberis | monēbitur |
| 3 | regar | regēris | regētur |
| 3io | capiar | capiēris | capiētur |
| 4 | audiar | audiēris | audiētur |

### 5.5 完成系统主动

以 amō 为例：

| | 完成 | 过去完成 | 将来完成 |
|---|---|---|---|
| 1sg | amāvī | amāveram | amāverō |
| 2sg | amāvistī | amāverās | amāveris |
| 3sg | amāvit | amāverat | amāverit |
| 1pl | amāvimus | amāverāmus | amāverimus |
| 2pl | amāvistis | amāverātis | amāveritis |
| 3pl | amāvērunt | amāverant | amāverint |

### 5.6 完成系统被动

| | 结构 | amō 例 |
|---|---|---|
| 完成 | PPP + sum | amātus sum |
| 过去完成 | PPP + eram | amātus eram |
| 将来完成 | PPP + erō | amātus erō |

> PPP 像形容词一样与主语**同性数**：amāta est（她已被爱）、amātī sunt（他们已被爱）。

## 6. 词尾同形与易混提醒

| 形式 | 形 | 可能身份 |
|---|---|---|
| -it | amat / amāvit | 3sg 现在（短 a）vs 3sg 完成（长 ā） |
| -īs | amās / amāvis | 2sg 现在 vs 2sg 完成（长度不同） |
| -ris/-re | amāris / amāre | 2sg 被动 vs 不定式 |
| -minī | amāminī | 2pl 被动（命令式亦同形） |
| -ērunt/-ēre | amāvērunt / amāvēre | 3pl 完成（诗体用 -ēre） |
| -ō | amō / amāverō | 1sg 现在 vs 1sg 将来完成（长 ā + -verō） |

## 7. 一页自测

1. *capiō* 的现在词干？→ capi-
2. *regō* 的未完成时 1sg？→ regēbam
3. *audiō* 的将来时 3sg 被动？→ audiētur
4. *moneō* 的完成时 3pl？→ monuērunt
5. *dūcō* 的被动完成 3sg（阳性）？→ ductus est
