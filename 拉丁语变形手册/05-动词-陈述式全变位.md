## 7. 主动 ↔ 被动 转换速查

| 主动 | 被动 |
|---|---|
| 现在 -ō/-m … | -or/-r … |
| 未完成 -bam … | -bar … |
| 将来 -bō … / -am … | -bor … / -ar … |
| 完成 -ī … | PPP + sum |
| 过去完成 -eram … | PPP + eram |
| 将来完成 -erō … | PPP + erō |

**及物性限制**：不及物动词（eō, veniō, dormiō…）没有真正的被动，只有**无人称被动**（itur「人们去」、ventum est「人们来了」）。
