# 03 · 代词、限定词、数词

> 代词的特点：词干固定、词尾有「-īus / -ī」型特殊属格与与格；指示代词多有「-ius/-ī」。
> 先记**词干**，再看词尾表，比死背整表快。

---

## 1. 人称代词

| | 我 | 你 | 我们 | 你们 |
|---|---|---|---|---|
| N | ego | tū | nōs | vōs |
| G | meī | tuī | nostrum / nostrī | vestrum / vestrī |
| D | mihi | tibi | nōbīs | vōbīs |
| Acc | mē | tē | nōs | vōs |
| Abl | mē | tē | nōbīs | vōbīs |

- **nostrum / vestrum** = 部分属格（我们中的）；**nostrī / vestrī** = 客观属格（对我们的）。
- 夺格带前置词 **cum** 时写作 **mēcum, tēcum, nōbīscum, vōbīscum**（连写）。

## 2. 反身代词 suī

| | 单复数同形 |
|---|---|
| N | —（无主格） |
| G | suī |
| D | sibi |
| Acc | sē (sēsē) |
| Abl | sē (sēsē) |

**用法区别**：

| 形式 | 指代 |
|---|---|
| **sē / suus** | 指**主语自身**（反身） |
| **eum / eius / eōrum** | 指**别人**（非反身） |
| **ipse** | 「本人、亲自」（强调同一人） |

> 例：Pater fīlium **suum** amat.（父亲爱**他自己的**儿子——suus 指主语 pater）
> Caesar **suōs** mīlitēs hortātus est.（凯撒鼓励**他自己的**士兵）
>
> **易错**：间接引语 *Pater dīcit fīlium sē amāre* 里 sē 指**主句主语** pater（「父亲说儿子爱他/父亲」），歧义时拉丁人用 **ipsum** 或改写。

## 3. 物主形容词

| 人称 | 阳性 | 阴性 | 中性 |
|---|---|---|---|
| 我的 | meus | mea | meum |
| 你的 | tuus | tua | tuum |
| 他的/她的/它的（反身） | suus | sua | suum |
| 我们的 | noster | nostra | nostrum |
| 你们的 | vester | vestra | vestrum |

- 变格同 **bonus**（noster 保留 e：noster, nostra, nostrum；vester 同）。
- 呼格阳性单数：**mī**（mī fīlī）、**mī** 用于 meus。

## 5. 关系代词 quī, quae, quod（＝英文 who/which/that）

| | 阳性 | 阴性 | 中性 |
|---|---|---|---|
| Sg N | quī | quae | quod |
| G | cuius | cuius | cuius |
| D | cuī | cuī | cuī |
| Acc | quem | quam | quod |
| Abl | quō | quā | quō |
| Pl N | quī | quae | quae |
| G | quōrum | quārum | quōrum |
| D | quibus | quibus | quibus |
| Acc | quōs | quās | quae |
| Abl | quibus | quibus | quibus |

- 关系代词的**格由它在从句中的成分决定**，性数由先行词决定：
  > urbs **quam** vīdī（我看到的城市）——urbs 阴性单数，quam 是宾语 → 宾格阴性单数。
- 可作连接关系代词：**quod** = 「这一点」；**quī** 引导目的/结果从句。

## 6. 疑问代词 / 疑问形容词

| | 阳性/阴性 | 中性 |
|---|---|---|
| N | quis | quid |
| G | cuius | cuius |
| D | cuī | cuī |
| Acc | quem | quid |
| Abl | quō | quō（阴性 quā） |

- **quis / quid** 作名词（谁/什么）；**quī / quae / quod** 作形容词（哪个……），变格同关系代词。
- 复合：**quisnam?** **ecquis?** **quīnam?**（到底谁/哪个）。
- **uter**（两者中哪个）变格同 -īus 型：utrīus, utrī。

## 7. 不定代词与限定词

| 词 | 义 | 变格要点 |
|---|---|---|
| **aliquis, aliquid** | 某人/某物 | ali- + quis；aliquā 等 |
| **quīdam, quaedam, quiddam (quoddam)** | 某个 | **quendam, quandam**；quōrundam |
| **quisque, quaeque, quidque (quodque)** | 每一个 | 最高级 + quisque |
| **quispiam, quaepiam, quippiam** | 某个（少见） | |
| **quisquam, quidquam (quicquam)** | 任何人（多用于否定） | 无复数 |
| **nescio quis / aliquī** | 不知谁 | |
| **ipse, ipsa, ipsum** | 本人、亲自 | ipsīus, ipsī |
| **alius, alia, aliud** | 别的 | alīus/alterīus, aliī |
| **alter, altera, alterum** | 另一个（两者） | alterīus, alterī |
| **uter, utra, utrum** | 两者中哪个 | utrīus, utrī |
| **uterque, utraque, utrumque** | 两者都 | utrīusque |
| **neuter, neutra, neutrum** | 两者都不 | neutrīus |
| **tālis, tāle** | 这样的 | 第三变格 |
| **quālis, quāle** | 什么样的 | 第三变格 |
| **tantus, -a, -um** | 这么大 | 同 bonus |
| **quantus, -a, -um** | 多大 | 同 bonus |
| **tot** | 这么多（不变） | 不变格 |
| **quot** | 多少（不变） | 不变格 |

| Acc | ipsum | ipsam | ipsum |
| Abl | ipsō | ipsā | ipsō |
| Pl N | ipsī | ipsae | ipsa |
| G | ipsōrum | ipsārum | ipsōrum |
| D | ipsīs | ipsīs | ipsīs |
| Acc | ipsōs | ipsās | ipsa |

## 9. 时间与日期表达

| 表达 | 结构 | 例 |
|---|---|---|
| 在某个时间点 | **夺格** | hōc annō（今年）、hōrā tertiā（第三时） |
| 持续多久 | **宾格** | trēs hōrās（三小时） |
| 在多久之内 | **夺格** | tribus diēbus（三天内） |
| 年龄 | annōs + 数词 + nātus | annōs vīgintī nātus（二十岁） |
| 日期（罗马式） | ante diem + 序数 + Kalendās/Nōnās/Īdūs | ante diem tertium Kalendās Mārtiās（三月朔日前第三天＝2月27日） |

- 每月固定日：**Kalendae**（朔日，1 号）、**Nōnae**（5 或 7 号）、**Īdūs**（13 或 15 号）。
