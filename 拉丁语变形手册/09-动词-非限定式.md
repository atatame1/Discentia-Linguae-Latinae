# 09 · 动词：非限定式（不定式 / 分词 / 动名词 / 动形词 / 目的分词）

> 非限定式不随人称变，但**有时态**（现在/完成/将来）、**有语态**、**要变格**（分词、动名词、动形词）。

---

## 1. 不定式总表

### 1.1 以 amō（第一变位）为例

| | 主动 | 被动 |
|---|---|---|
| 现在 | amāre 爱 | amārī 被爱 |
| 完成 | amāvisse 已经爱 | amātum esse 已经被爱 |
| 将来 | amātūrum esse 将要爱 | amātum īrī 将要被爱 |

### 1.2 以 regō（第三变位）为例

| | 主动 | 被动 |
|---|---|---|
| 现在 | regere | **regī** |
| 完成 | rēxisse | rēctum esse |
| 将来 | rēctūrum esse | rēctum īrī |

### 1.3 全部变位的现在不定式

| 变位 | 主动 | 被动 |
|---|---|---|
| 1 amō | amāre | amārī |
| 2 moneō | monēre | monērī |
| 3 regō | regere | regī |
| 3io capiō | capere | **capī** |
| 4 audiō | audīre | **audīrī** |
| sum | esse | —— |
| possum | posse | —— |
| ferō | ferre | ferrī |
| eō | īre | īrī（无人称） |
| volō | velle | —— |
| nōlō | nōlle | —— |
| mālō | mālle | —— |
| fiō | fierī | —— |
| **异态** sequor | **sequī** | —— |

> **被动不定式词尾**：1/2 变位 -rī；3 变位 -ī；4 变位 -īrī（长 ī + rī）。

## 2. 分词：四种（+ 异态的第五种）

| 分词 | 主动 | 被动 | 变格 |
|---|---|---|---|
| 现在 | **-ns, -ntis**（amāns） | —— | 第三变位（夺格 -e；属格复 -ium） |
| 完成 | 异态才有（secūtus） | **-tus, -a, -um**（amātus） | 第一/二变位 |
| 将来 | **-tūrus**（amātūrus） | **-ndus**（=动形词，amandus） | 第一/二变位 |

### 2.1 现在分词变格（amāns, amantis 爱着的）

| | 阳/阴 | 中性 |
|---|---|---|
| Sg N | amāns | amāns |
| G | amantis | amantis |
| D | amantī | amantī |
| Acc | amantem | amāns |
| Abl | amante | amante |
| Pl N | amantēs | amantia |
| G | amantium | amantium |
| D | amantibus | amantibus |
| Acc | amantēs | amantia |
| Abl | amantibus | amantibus |

> 第三变位现在分词：regēns, regentis；第四：audiēns, audientis；**eō → iēns, euntis**（不规则）。

### 2.2 完成被动分词（PPP）与将来主动分词

- **PPP**（amātus, -a, -um）：与名词同变，兼作「完成被动分词」和「完成被动系统」的基础。
- **-tūrus**（amātūrus）：将来主动分词，「将要……的」；与 **sum** 连用构成**主动迂说变位**：amātūrus sum「我即将爱」。
- **-ndus**：动形词（见 §4），兼作「将来被动分词」。

---

## 3. 动名词（Gerundium）

> 动词的**名词化**，只用于 oblique cases（属、与、宾、夺），主动义。

| 格 | 形（amō） | 用法 |
|---|---|---|
| 属格 | amandī | 目的/原因属格（后置 causā / grātiā）：**amandī causā** 为了爱 |
| 与格 | amandō | 少见（多被动形词替代） |
| 宾格 | amandum | ad amandum 为了爱 |
| 夺格 | amandō | in amandō 在爱中 |

- 构成：**现在词干 + -nd-** + 第二变位中性词尾（-ī, -ō, -um, -ō）。
- 第三/四变位加 **-e-**：regendī, audiendī；capiō → capiendī。
- 动词有宾语时用**动形词**更常见：*ad urbem capiendam*（为了攻占城市）。

---

## 4. 动形词（Gerundīvum）

> **-ndus, -a, -um**，表示「应当被……的」，被动义务。

| 用法 | 结构 | 例 |
|---|---|---|
| 义务（与 sum） | 动形词 + est/erant | *Urbs capienda est.* 城应当被攻下。 |
| 目的（ad + 宾格） | ad + 动形词 | *ad urbem capiendam* 为了攻下城市 |
| 属格（原因/特征） | 动形词属格 | *cupidus urbis capiendae* 渴望攻下城市 |
| 与格（职责） | 动形词与格 | *urbs capienda mihi est* 我应当攻下城（被动迂说） |
| 夺格（方式） | 动形词夺格 | *in urbe capiendā* 在攻城中 |

- 构成：**现在词干 + -ndus**（1/2）；3/4 加 -e-（regendus, audiendus）。
- 与 sum 构成**被动迂说变位**：amandus est「他应当被爱」；amandus erat「他当时应当被爱」。

---

## 5. 目的分词（Supine）

| 格 | 形 | 用法 |
|---|---|---|
| 宾格 | **-tum** | 表「目的」，常与 **ad** 或运动动词连用：*vēnit spectātum* 他来看 |
| 夺格 | **-tū** | 只与少数形容词连用：*facile dictū* 说起来容易；*mīrābile vīsū* 看起来奇妙 |

- 例：*lēgātī vēnērunt pācem petītum.* 使节们来求和平。
- 例：*difficile est factū.* 做起来难。

---

## 6. 迂说变位（Periphrastic）

| 类型 | 结构 | 义 | 例 |
|---|---|---|---|
| 主动将来 | **-tūrus + sum** | 将要…… | amātūrus sum 我即将爱 |
| 被动义务 | **-ndus + sum** | 应当被…… | amandus sum 我应当被爱 |
| 完成被动（常规） | PPP + sum | 已被…… | amātus sum 我已被爱 |

> 迂说变位可套进所有时态：amātūrus eram（我本来将要爱）、amandus erō（我将应当被爱）。

---

## 7. 异态动词的非限定式

以 **sequor** 为例：

| 形式 | 形 | 义 |
|---|---|---|
| 现在不定式 | sequī | 跟随 |
| 完成不定式 | secūtum esse | 已经跟随 |
| 将来不定式 | secūtūrum esse | 将要跟随 |
| 现在分词 | sequēns, sequentis | 跟随着的（主动） |
| 完成分词 | secūtus, -a, -um | 已经跟随的（**主动义**） |
| 将来分词 | secūtūrus | 将要跟随的 |
| 动形词 | sequendus | 应当被跟随的 |
| 动名词 | sequendī | 跟随（这件事） |

> 异态动词的「完成分词」形似 PPP，但**意思是主动的**：secūtus = 「已经跟随了」，不是「被跟随」。

---

## 8. 不定式的句法功能

| 功能 | 例 | 译 |
|---|---|---|
| 宾语不定式（间接引语） | Dīcit eum venīre. | 他说他来。 |
| 主语不定式 | Errare hūmānum est. | 犯错是人之常情。 |
| 补充动词 | Possum īre. / Volō īre. | 我能去。/ 我想去。 |
| 目的（诗体） | Vēnit vidēre. | 他来看。 |
| 感叹 | Tē vidēre! | 见到你！ |

**间接引语时态**：主句动词为现在 → 不定式时态照原话；主句为过去 → 现在不定式 = 同时，完成不定式 = 先时，将来不定式 = 后时。
