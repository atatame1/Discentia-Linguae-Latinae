# 12 · 句法（二）：从句与句式

> 11 册讲「一个格能表达什么」，这一册讲「一个句子怎么搭起来」。
> 拉丁从句只有两条主线：**语气**（陈述式／虚拟式）与**相对时态**（同时／先时／后时）。抓住这两条，再长的句子也能拆。

---

## 1. 词序：没有固定语序，但有默认语序

**默认 SOV**：主语 → 间接宾语 → 直接宾语 → 状语 → **动词**。

> *Caesar mīlitibus praedam dedit.* 凯撒把战利品给了士兵。

| 位置 | 通常放什么 | 效果 |
|---|---|---|
| 句首 | 主题、对比成分、疑问词、连接词 | 强调、承接上文 |
| 第二位置 | enim, autem, vērō, igitur, quidem, quoque | 语气、转折 |
| 句末 | 动词、新信息 | 强调（最重要的信息常压在这里） |
| 名词后 | 形容词、属格、同位语 | 常规修饰 |
| 名词前 | 指示词、数量词、强调性形容词 | 限定、强调 |

**六条具体规则**：

1. **动词常在句末**；句末是强调位。*Fortēs fortūna iuvat.* 命运帮助勇者。
2. **形容词后置是常态**，前置即强调：*magnus vir* 比 *vir magnus* 更有力。
3. **属格在被修饰名词后**：*domus Caesaris*。
4. **介词前置**，但可插入形容词与名词之间：*magnā cum laude*。
5. **est / sunt 常省略**：*Fortēs fortūna iuvat* 里没有「是」。
6. **否定词紧贴动词**；疑问词句首；**-ne 附在第一个词**后。

**修辞性语序**（读原文必须认得）：

| 手法 | 说明 | 例 |
|---|---|---|
| 交错 chiasmus | ABBA 排列（形容词A—名词A—名词B—形容词B） | 多见于诗歌与演说，读时注意配对 |
| 分离 hyperbaton | 形容词与名词被拉开 | *magnā cum laude*；*multās per gentēs* |
| 省略 ellipsis | 省略 sum、宾语、系词 | *Fortēs fortūna iuvat*（无 est） |

## 2. 同位语

同位语与被说明的成分**同格**，可带修饰语。

| 类型 | 例 | 译 |
|---|---|---|
| 人名 + 身份 | *Cicerō, cōnsul Rōmānus* | 西塞罗，罗马执政官 |
| 城市 + 通名 | *urbs Rōma* | 罗马城 |
| 河流 + 通名 | *flūmen Rhēnus* | 莱茵河 |
| 代词 + 名词 | *nōs cōnsulēs* | 我们这些执政官 |
| 全句指代 | *quod, quae rēs* | 而这一点…… |

> 同位语不改变格：*Patrem meum, virum fortissimum, vīdī.* 我看到我父亲——一位极勇敢的人。（两个都是宾格）

## 3. 关系从句：四型 + 两特殊

**核心规则**：关系代词的**性、数**由先行词决定，**格**由它在从句中的成分决定。

> *Urbs **quam** vīdī magna est.* 我看见的那座城很大。（urbs 阴性单数 → quam 阴性单数；在从句中作宾语 → 宾格）

| 类型 | 语气 | 标志 | 例 |
|---|---|---|---|
| 限定／描述 | 陈述 | 无 | *Urbs quam vīdī magna est.* |
| **目的** | 虚拟 | quī = ut is | *Lēgātōs mīsit quī pācem peterent.* 他派使节去求和。 |
| **结果** | 虚拟 | 先行词前有 tam / tālis / tantus / adeō | *Nēmō tam stultus est quī hoc crēdat.* 没人蠢到会信这个。 |
| **因果／让步** | 虚拟 | quī = cum is | *Caesar, quī omnia scīret, tamen cautē ēgit.* 凯撒虽知一切，仍谨慎行事。 |
| **特征／泛指** | 虚拟 | sunt quī, nēmō est quī, dignus quī | *Sunt quī putent…* 有人认为…… |
| 连接关系 | 陈述 | quī = et is | *Lēgātōs mīsit, quī vēnērunt.* 他派了使节，他们来了。 |

**两个高频特殊结构**：

- **dignus / indignus / idōneus / aptus + quī + 虚拟**：*Dignus est quī imperet.* 他配得上统治。
- **quī 表目的时，格仍由从句成分决定**：*Lēgātōs mīsit **quī** pācem peterent*（quī 作主语 → 主格）；*lēgātōs mīsit **quibus** imperāret*（quibus 作与格宾语）。

## 4. 间接陈述：宾格 + 不定式

**结构**：主句动词（说、想、知、感）+ **宾格主语** + **不定式**。

| 主句动词 | 例 |
|---|---|
| dīcō, negō, ait, inquit | *Dīcit sē venīre.* |
| putō, crēdō, arbitror, opīnor | *Putō eum venīre.* |
| sciō, cōgnōscō, intellegō, sentiō | *Sciō eum vēnisse.* |
| audiō, videō, nūntiō, scrībō | *Audiō eum ventūrum esse.* |
| spērō, prōmittō, polliceor | *Spērō fore ut veniat.* |

**时态是相对的**（这一点和汉语「他说他来过／来／会来」一致，但形式必须严格对应）：

| 不定式 | 相对时间 | 例（主句为过去） |
|---|---|---|
| 现在不定式 | 同时 | *Dīxit sē venīre.* 他说他当时来。 |
| 完成不定式 | 先时 | *Dīxit sē vēnisse.* 他说他之前来过。 |
| 将来不定式 | 后时 | *Dīxit sē ventūrum esse.* 他说他会来。 |

**反身代词是关键**：

| 形式 | 指谁 | 例 |
|---|---|---|
| **sē / suus** | 主句主语 | *Dīxit sē vīdisse.* 他说他（自己）看见了。 |
| eum / eius / illum | 别人 | *Dīxit sē eum vīdisse.* 他说他看见了那个人。 |

**四个必记细节**：

1. **negō = dīcō nōn**：*Negō mē ventūrum esse.* 我说我不会来。
2. **被动不定式**：*Dīcitur hostēs victōs esse.* 据说敌人已被击败。
3. **将来被动不定式** *amātum īrī* 少见（见 09 册 §1.1），更常用 **fore ut / futūrum esse ut + 虚拟**：
   > *Spērō fore ut urbs capiātur.* 我希望城会被攻下。
4. **dīcitur 型**（主格 + 不定式），拉丁人偏爱这种被动说法：
   > *Caesar venīre dīcitur.* 据说凯撒来了。／*Rōmānī victī esse dīcuntur.* 据说罗马人败了。

> **不要混淆**：iubeō / vetō / cōgō / volō / possum 后面接的是**补充不定式**，不是间接陈述，主语用主格。
> *Iubeō tē īre.* 我叫你去。（tē 是宾语，不是间接陈述的主语）

## 5. 间接疑问

**结构**：疑问词 + **虚拟式**。时态按序列。

| 直接问 | 间接问 |
|---|---|
| *Quid facis?* | *Rogō quid faciās.* 我问你在做什么。 |
| *Ubi est?* | *Nesciō ubi sit.* 我不知道他在哪。 |
| *Venietne?* | *Dubitō num ventūrus sit.* 我怀疑他是否会来。 |
| *Cūr abiit?* | *Rogāvit cūr abīsset.* 他问为什么走了。 |

- 疑问词包括：quis, quid, quī, ubi, quandō, cūr, quōmodo, quantus, uter, num, -ne。
- **拉丁语的间接疑问绝不用陈述式**（英语可以，拉丁不行）。
- 序列：主要序列 → 现在／完成虚拟；次要序列 → 未完成／过去完成虚拟。

---

## 6. 间接命令

**结构**：ut / nē + **虚拟式**。

| 主句动词 | 例 |
|---|---|
| imperō, mandō, praecipiō, edīcō | *Imperāvit ut venīret.* 他命令他来。 |
| rogō, ōrō, petō, postulō | *Petīvit ut sibi licēret.* 他请求准许。 |
| hortor, moneō, suādeō, persuādeō, cēnseō | *Mīlitēs hortātus est ut fortiter pugnārent.* |

- 否定用 **nē**：*Nē venīret imperāvit.* 他命令他不要来。
- **例外**：iubeō（命令）、vetō（禁止）、cōgō（强迫）接**不定式**，不用 ut。
  > *Iussit eum venīre.* 他命令他来。／*Vetuit eum venīre.* 他禁止他来。

---

## 7. 目的从句

**结构**：ut / nē + **现在或未完成虚拟**（按序列，只用这两个时态）。

| 主句时态 | 目的从句 | 例 |
|---|---|---|
| 现在／将来 | 现在虚拟 | *Venit ut videat.* 他来是为了看。 |
| 过去 | 未完成虚拟 | *Vēnit ut vidēret.* 他来了是为了看。 |

> **一个长音决定时态**：*Venit*（现在，「他来」）→ videat；*Vēnit*（完成，「他来了」）→ vidēret。这就是全书标 macron 的实际用处。

**目的的六种替代表达**：

| 手段 | 例 | 备注 |
|---|---|---|
| ut / nē | *ut vidēret* | 最标准 |
| quī + 虚拟 | *mīsit quī peterent* | 有先行词时 |
| quō + 比较级 | *quō facilius intellegātis* | 从句含比较级时 |
| ad + 动形词 | *ad urbem capiendam* | 目的性最强 |
| 属格动名词 + causā / grātiā | *urbis capiendae causā* | 正式 |
| supine -tum | *vēnit spectātum* | 仅限运动动词 |

> **否定只能用 nē**。*ut nōn 是结果从句的否定，不是目的。

---

## 8. 结果从句

**结构**：ut / **ut nōn** + 现在或未完成虚拟。

**标志词**（看到它们就要预期结果从句）：

| 标志 | 义 | 例 |
|---|---|---|
| tam | 如此（修饰形容词／副词） | *Tam bonus est ut omnēs eum ament.* |
| ita / sīc | 如此（修饰动词） | *Ita fessus est ut ambulāre nōn possit.* |
| adeō | 到如此程度 | *Adeō perturbātus est ut respondēre nōn posset.* |
| tantus / tālis | 如此大／如此这般 | *Tanta vīs est ut…* |
| tot / totiēns | 如此多／如此多次 | *Tot vulnera passus est ut…* |

**固定搭配**：

> *Accidit ut…* 碰巧……｜*Fit ut…* 结果是……｜*Efficitur ut…* 导致……｜*Sequitur ut…* 由此得出……｜*Mōs est ut…* 习俗是……

> **目的 vs 结果速判**：有 tam / ita / tantus 等标志，且否定用 **ut nōn** → 结果；无标志、否定用 **nē** → 目的。

---

## 9. 原因从句

| 连词 | 语气 | 含义 | 例 |
|---|---|---|---|
| quod, quia, quoniam, quandō, siquidem | 陈述 | 事实原因 | *Quod valēs, gaudeō.* 你健康，我很高兴。 |
| **quod** | **虚拟** | 转述的理由（别人说的，说话人不担保） | *Sōcratēs accūsātus est quod iuventūtem corrumperet.* |
| **cum** | **虚拟** | 因为（带主观色彩） | *Cum vēnisset, gāvīsī sunt.* 因为他来了，他们很高兴。 |

- 复合连词：*proptereā quod*、*ideō quia*、*eō quod*。
- **quod 的虚拟式是拉丁语最微妙的地方之一**：它不是「假原因」，而是「说话人把理由归于别人」。

## 10. 时间从句与 cum 的五种

### 10.1 cum

| 类型 | 语气 | 义 | 例 |
|---|---|---|---|
| 纯时间 | 陈述 | 当……时 | *Cum vēnit, abiit.* |
| 情境（circumstantial） | 虚拟 | 当……时（带背景色彩） | *Cum haec dīxisset, abiit.* 他说完这些就走了。 |
| 因果 | 虚拟 | 因为 | *Cum vēnisset, gāvīsī sunt.* |
| 让步 | 虚拟 | 虽然 | *Cum omnia scīret, tamen cautē ēgit.* |
| **cum inversum** | 虚拟 | 刚……就 | *Vix ea dīxerat, cum vēnit.* 他刚说完，那人就来了。 |

### 10.2 其他时间连词

| 连词 | 语气 | 义 |
|---|---|---|
| postquam | 陈述（多用完成时） | 在……之后 |
| antequam / priusquam | 陈述；虚拟表意图或预期 | 在……之前 |
| dum | 陈述 = 当……时／只要；虚拟 = 直到 | *Dum spīrō, spērō.* 一息尚存，我便希望。 |
| dōnec / quoad | 陈述或虚拟 | 直到 |
| ubi, ut, simul ac / atque, ut prīmum, cum prīmum | 陈述 | 一……就 |

## 11. 让步从句

| 连词 | 语气 | 例 |
|---|---|---|
| quamquam | **陈述**（只此一个） | *Quamquam difficile est, tamen cōnābor.* |
| quamvīs, licet | 虚拟 | *Quamvīs dīves sit, tamen nōn beātus est.* |
| cum | 虚拟 | *Cum omnia scīret, tamen…* |
| etsī, etiamsī, tametsī | 陈述或虚拟 | *Etsī hoc vērum est, tamen…* |

> **quamquam 是最容易错的**：它**只带陈述式**。看到 quamquam 后面是虚拟式，就要怀疑文本或自己的判断。

## 12. 条件句：六型（附混合型）

| 类型 | 条件句（sī） | 主句 | 例 |
|---|---|---|---|
| 简单·现在 | 现在陈述 | 现在陈述 | *Sī valēs, gaudeō.* 你若健康，我就高兴。 |
| 简单·过去 | 过去陈述 | 过去陈述 | *Sī vēnit, gāvīsus est.* 他若来了，就高兴了。 |
| **将来·更生动** | 将来陈述／将来完成 | 将来陈述 | *Sī veniet, gaudēbō.*／*Sī vēnerit, gaudēbō.* |
| **将来·较不生动** | 现在虚拟 | 现在虚拟 | *Sī veniat, gaudeam.* 他若来（未必来），我就高兴。 |
| **现在反事实** | 未完成虚拟 | 未完成虚拟 | *Sī venīret, gaudērem.* 他若现在来（其实没来），我就会高兴。 |
| **过去反事实** | 过去完成虚拟 | 过去完成虚拟 | *Sī vēnisset, gāvīsus essem.* 他若当时来了，我就高兴了。 |
| 混合 | 过去完成虚拟 | 未完成虚拟 | *Sī vēnisset, nunc gaudērem.* 他若当时来了，我现在就高兴了。 |

**要点**：

- **反事实的时态比汉语「退一步」**：现在反事实用未完成虚拟，过去反事实用过去完成虚拟。
- **nisi** = if not；**sīn** = but if（另起一条件）；**nisi vērō** = unless indeed。
- **dummodo / modo** = 只要（+ 虚拟）：*Modo veniat, gaudeam.*
- 条件句常省主句：*Sī vērō…* 「若果然如此（那就……）」。

## 13. 担心、疑虑、预防

| 类型 | 结构 | 例 |
|---|---|---|
| 担心（怕发生） | timeō / vereor / metuō + **nē** + 虚拟 | *Timeō nē veniat.* 我怕他会来。 |
| 担心（怕不发生） | **timeō ut** + 虚拟，或 nē nōn | *Timeō ut veniat.* 我怕他不来。 |
| 疑虑 | dubitō **an / num** + 虚拟 | *Dubitō an ventūrus sit.* 我怀疑他会不会来。 |
| 毫无疑问 | **nōn dubitō quīn** + 虚拟 | *Nōn dubitō quīn ventūrus sit.* 我确信他会来。 |
| 阻止／拒绝 | impediō, prohibeō, recūsō + **quīn / quōminus** + 虚拟 | *Nōn prohibuit quīn venīret.* 他没有阻止他来。 |

> **nē 与 ut 在这里是反的**：*timeō nē* 怕「会发生」，*timeō ut* 怕「不会发生」。这是拉丁语最反直觉的一处。

## 14. 迂说变位

| 类型 | 结构 | 义 | 例 |
|---|---|---|---|
| 主动将来 | **-tūrus + sum** | 将要…… | *Amātūrus sum.* 我即将爱。 |
| 被动义务 | **-ndus + sum** | 应当被…… | *Amandus sum.* 我应当被爱。 |
| 完成被动 | PPP + sum | 已被…… | *Amātus sum.* 我已被爱。 |

可套进全部时态：

> *Amātūrus eram.* 我本来将要爱。｜*Amandus erō.* 我将应当被爱。｜*Amandum erat.* 当时应当被爱。
> 被动义务的施事用**与格**：*Mihi agendum est.* 我应当做。

## 15. 动名词 / 动形词 / 目的分词的句法分工

| 结构 | 何时用 | 例 |
|---|---|---|
| 动名词（gerund） | 动词**无宾语**时 | *ars amandī* 爱的艺术 |
| **动形词（gerundive）** | 动词**有宾语**时，宾语与动形词同格数性 | *ars urbis capiendae* 攻城的艺术 |
| ad + 动形词 | 目的 | *ad urbem capiendam* 为了攻城 |
| 属格动形词 + causā / grātiā | 目的（正式） | *urbis capiendae causā* |
| supine -tum | 运动动词后表目的 | *vēnit spectātum* 他来看 |
| supine -tū | 少数形容词后表方面 | *facile dictū* 说起来容易 |

> **一条实用判据**：宾语出现 → 用动形词，让宾语跟动形词一起变格；没有宾语 → 用动名词。

## 16. 易错点

| # | 坑 | 正解 |
|---|---|---|
| 1 | 间接陈述用 quod 从句 | 拉丁用**宾格 + 不定式**；quod 从句是中世纪／通俗用法 |
| 2 | 间接疑问用陈述式 | 必须虚拟式 |
| 3 | 目的从句否定用 ut nōn | 用 **nē**；ut nōn 属结果 |
| 4 | 结果从句否定用 nē | 用 **ut nōn** |
| 5 | timeō nē 译成「怕不」 | timeō nē = 怕「会」；timeō ut = 怕「不会」 |
| 6 | quamquam 后接虚拟 | 只接陈述式 |
| 7 | cum 一律译「当」 | cum + 虚拟还可表因为、虽然 |
| 8 | 反事实用现在时 | 现在反事实用未完成虚拟，过去用过去完成虚拟 |
| 9 | sē 指别人 | sē 指主句主语；别人用 eum / illum |
| 10 | iubeō 后接 ut | iubeō / vetō / cōgō 接不定式 |
| 11 | 关系代词格跟着先行词 | 性数跟先行词，**格看从句成分** |
| 12 | 动名词带宾语 | 有宾语时改用动形词 |

## 17. 一页自测

1. *Dīxit sē ventūrum esse.* 他什么时候来？→ 说话之后的将来（后时）
2. *Dīxit sē vēnisse.* 与 *Dīcit sē vēnisse.* 的差别？→ 不定式都表先时，差别只在主句时态：「他说过」／「他说」
3. *Timeō nē veniat.* 与 *Timeō ut veniat.* → 怕他来／怕他不来
4. *Tam fortis est ut nēmō eum vincat.* 什么从句？→ 结果（tam 标志）
5. *Venit ut videat.* 与 *Vēnit ut vidēret.* → 现在主句用现在虚拟；完成主句用未完成虚拟
6. *Sī venīret, gaudērem.* 事实是什么？→ 他现在没来（现在反事实）
7. *Cum haec dīxisset, abiit.* 的 cum 译什么？→ 「说完……就」，情境／先时
8. *Nōn dubitō quīn ventūrus sit.* 说话人态度？→ 确信他会来
9. *Ars urbis capiendae.* 为什么用动形词而不是动名词？→ 有宾语 urbis，宾语与动形词同格
10. *Iussit eum venīre.* 为什么不是 ut venīret？→ iubeō 接不定式
