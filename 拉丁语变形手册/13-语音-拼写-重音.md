# 13 · 语音、拼写与重音

> 拉丁语的格、时态、重音都靠**音长**区分。读不出声，记忆效率会差一半。
> 这一册解决三件事：**怎么念**、**怎么分音节**、**重音落在哪**。

---

古典拉丁没有 **J、U、W**：辅音 u 写作 u（或现代写作 v），辅音 i 写作 i（或现代写作 j）。
**K、Y、Z** 主要用于希腊借词。

## 2. 元音：长短辨义

长短不是音质差别，是**时长**差别（约 2:1）。它同时承担三种功能：辨词义、辨格、辨时态。

| 长 | 短 | 区别 |
|---|---|---|
| mālum 苹果 | malum 恶 | 词义 |
| līber 自由的 | liber 书 | 词义 |
| ōs 嘴 | os 骨 | 词义 |
| pōpulus 白杨 | populus 人民 | 词义 |
| vēnit 他来了 | venit 他来 | 时态 |
| lēgit 他读了 | legit 他读 | 时态 |
| lātus 宽的 | latus 侧、边 | 词义 |
| pālus 木桩 | palus 沼泽 | 词义 |

> **这是全书标 macron 的根本理由**：不标长音，*vēnit / venit*、*līber / liber* 在纸面上完全同形，读的时候也无从判断重音。

## 3. 双元音

| 双元音 | 音 | 例 |
|---|---|---|
| ae | [ai] | aquae, puellae, saepe, Caesar |
| au | [au] | aurum, laudō, auris |
| ei | [ei] | deinde, hei |
| eu | [eu] | seu, neuter（多为希腊词） |
| oe | [oi] | poena, coepī, proelium |
| ui | [ui] | cui, huic（huius 常读 [huj.jus]） |

- 双元音在诗歌中算**一个音节**。
- **ae / oe 不是两个元音分读**，除非标了分音符：*aër*（空气）、*poëta*（诗人）。
- 现代排印常用 **æ / œ**。

## 4. 辅音

| 字母 | 古典音 | 说明与例 |
|---|---|---|
| c | [k] | Cicerō [kikeroː]； Caesar [kaisar] |
| g | [g] | genus [genus]；magister [magister] |
| s | [s] | rosa [rosa]，不读 [z] |
| v | [w] | via [wia]；vīnum [wiːnum] |
| i（辅音） | [j] | iam [jam]；iūs [juːs] |
| qu | [kw] | aqua [akwa]；quī [kwiː] |
| gu（n 后） | [gw] | sanguis [sangwis]；lingua [lingwa] |
| gn | [ŋn] | magnus [maŋnus]；īgnis [iŋnis] |
| x | [ks] | dux [duks]；rēx [reːks] |
| z | [dz] | 希腊词：zōna |
| ch | [kʰ] | 希腊词：chorus；日常可读 [k] |
| ph | [pʰ] | philosophia；日常可读 [f] |
| th | [tʰ] | theātrum；日常可读 [t] |
| rh | [rʰ] | rhētor；日常可读 [r] |
| h | [h] | 轻送气，诗律中不算辅音 |

**两个中国学习者最常犯的错**：

1. 把 **c** 读成英语的 [s]（Cicerō 读成「西塞罗」）。古典音是 [kikeroː]，汉语音译「基凯罗」更接近。
2. 把 **v** 读成英语的 [v]（vīnum 读成「维努姆」）。古典音是 [wiːnum]，接近「wi」。

## 5. 音节划分

| # | 规则 | 例 |
|---|---|---|
| 1 | 元音之间的**单辅音归后**一音节 | a-mī-cus；pa-ter；le-gō |
| 2 | **双辅音分开** | pu-el-la；magis-ter；mit-tō |
| 3 | **塞音 + 流音**（p/b/t/d/c/g + l/r）可整体归后 | pa-trem；vo-lu-cris |
| 4 | **qu 视为单辅音** | a-qua；re-li-quus |
| 5 | **h 不计数** | ni-hil；a-hor?（罕见） |
| 6 | **复合词按词源分** | ab-eō；red-eō；in-īquus |
| 7 | 元音之间的 i / u 若为半元音，归后 | fī-li-us；iā-nu-a |

> 音节划分不是为了好看，而是为了**定重音**：只有先分对音节，才能判断倒数第二音节是长是短。

---

## 6. 音量规则

### 6.1 长音

| 类型 | 规则 | 例 |
|---|---|---|
| **自然长** | 长元音、双元音 | amāre 的 ā；puellae 的 ae |
| **位置长** | 元音后接**两个或以上辅音**（含 x、z；可跨音节） | pu-el-la 的 e 后接 ll；ma-gis-ter 的 i 后接 st |
| 位置长 | 双辅音 x / z 算两个 | dux 的 u；axis 的 a |
| 诗律 | 词尾辅音 + 下一词首辅音也可造成位置长 | 仅影响格律，不影响重音 |

### 6.2 短音

| 类型 | 规则 | 例 |
|---|---|---|
| 元音前的元音 | vocalis ante vocalem brevis | fī-li-us 的 i；iā-nu-a 的 u |
| 单辅音开头 | 元音后接单辅音，且该辅音属下一音节 | a-mī-cus 的 i |
| 词尾 | -a / -e / -i / -o / -u 多短 | aqua, mare, turri?（turrī 长） |

### 6.3 三个细节

1. **muta cum liquida**（塞音 + 流音）在诗律中**可短可长**：pa-trem 的 pa- 可作短音节。但**重音判断按短算**。
2. **qu 的 u 不算辅音**：re-li-quus 的 li 是短音节，重音前移到 re。
3. **h 不算辅音**：ni-hil 的 ni 不因 h 变长。

---

## 7. 重音

**三条规则**（与 00 册第七节一致，这里给完整例词）：

1. **双音节词**：重音永远在第一个音节。
2. **三音节及以上**：看**倒数第二音节**
   - 长 → 重音在倒数第二
   - 短 → 重音前移到倒数第三
3. **重音绝不落在最后一个音节。**

| 词 | 音节 | 倒数第二 | 重音 |
|---|---|---|---|
| amō | a-mō | ——（双音节） | **á**mō |
| regit | re-git | ——（双音节） | **ré**git |
| amāre | a-mā-re | mā 长 | a-**mā́**-re |
| amāvī | a-mā-vī | mā 长 | a-**mā́**-vī |
| amāveram | a-mā-ve-ram | ve 短 | a-**mā́**-ve-ram |
| fēmina | fē-mi-na | mi 短 | **fḗ**-mi-na |
| cōnsilium | cōn-si-li-um | li 短 | cōn-**sí**-li-um |
| puella | pu-el-la | el 长（位置） | pu-**él**-la |
| magister | ma-gis-ter | gis 长（位置） | ma-**gís**-ter |
| reliquus | re-li-quus | li 短（qu 单辅音） | **ré**-li-quus |
| imperātor | im-pe-rā-tor | rā 长 | im-pe-**rā́**-tor |
| fortitūdō | for-ti-tū-dō | tū 长 | for-ti-**tū́**-dō |
| fīlius | fī-li-us | li 短 | **fī́**-li-us |
| iānua | iā-nu-a | nu 短 | **iā́**-nu-a |
| nātūrālis | nā-tū-rā-lis | rā 长 | nā-tū-**rā́**-lis |
| amōrōsus | a-mō-rō-sus | rō 长 | a-mō-**rṓ**-sus |

### 7.1 附着词使重音后移

**-que, -ne, -ve** 附在词后时，重音落到**附着词前的那一音节**（即原词的末音节）。

| 原词 | 加附着词 | 重音 |
|---|---|---|
| arma virum | arma vi**rum**que | vi-**rúm**-que |
| tū | tū**ne**? | **tū́**-ne |
| Rōma | Rōma**ne**? | Rō-**má**-ne |

> 维吉尔 *Arma virumque canō* 的第一句，重音就是 *vi-rúm-que*，不是 *ví-rum-que*。

## 8. 古典发音 vs 教会发音

| 字母／组合 | 古典（Classical） | 教会（Ecclesiastical） |
|---|---|---|
| c + e/i/ae/oe | [k] | [tʃ]（Cicerō → 奇切罗） |
| g + e/i | [g] | [dʒ] |
| v | [w] | [v] |
| ae | [ai] | [ɛ] / [e] |
| oe | [oi] | [e] |
| gn | [ŋn] | [ɲ]（如意大利语 gn） |
| ti + 元音 | [ti] | [tsi]（gratiā → 格拉齐亚） |
| s（元音间） | [s] | [z]（部分传统） |
| h | [h] | 不发音 |
| z | [dz] | [dz] |

**怎么选**：

- 读古典文本、判断诗歌格律 → **古典**。
- 读教会文献、弥撒、文艺复兴音乐 → **教会**。
- **两者不能混用**：不能一边把 c 读 [tʃ]，一边按古典规则算音节长短。

## 9. 拼写变体

| 现象 | 说明 | 例 |
|---|---|---|
| u / v | 古典只写 u；现代用 v 标辅音 | servus / seruus |
| i / j | 古典只写 i；现代用 j 标辅音 | iam / jam |
| 同化 | 前缀末辅音受词根影响 | ad- + ferō → afferō；in- + legō → intellegō；com- + loquor → colloquor |
| 元音弱化 | 复合词中短元音变 i / e | faciō → perficiō；capiō → accipiō；caedō → occīdō |
| 古体拼法 | 早期拉丁 | optumus / optimus；servos / servus；quom / cum；volt / vult |
| 宾格复数 | -īs / -ēs 两写 | urbīs / urbēs |
| 夺格单数 | 纯 i 词干 -ī / -e 两写 | turrī / turre |

**本手册的写法**（读时请统一）：

- 用 **v** 表辅音 u，用 **i** 表辅音 i（不写 j），与多数英美教材一致。
- 标 **macron** 表长音；短音一般不标，必要时用 breve（ă）。
- 引原文时保留原书拼法，可能与本书不一致。

---

## 10. 诗歌中的省音（读原文时会遇到）

- **词末元音或 -m 遇下一词首元音（或 h）时省去**：
  > *multum ille* → 读作 *mult' ille*
  > *monstrum horrendum* → *monstr' horrendum*
- 省音不影响书写，只影响格律与朗读。
- 例外：感叹词 ō、名词的 -ī（第二变格属格）、短元音后的 est 常不省。

## 11. 朗读练习

先分音节，再标重音，最后连读。

| 句子 | 音节与重音（v 读 [w]） | 出处 |
|---|---|---|
| *Arma virumque canō* | ar-ma vi-**rúm**-que **cá**-nō | 维吉尔《埃涅阿斯纪》1.1 |

## 12. 易错点

| # | 坑 | 正解 |
|---|---|---|
| 1 | c 一律读 [s] | 古典音一律 [k] |
| 2 | v 读 [v] | 古典音 [w] |
| 3 | ae 分读成两个元音 | 是双元音 [ai]，一个音节 |
| 4 | 重音落在末音节 | 拉丁语重音绝不在末音节 |
| 5 | 见 -que 仍按原词重音 | 重音后移到 -que 前一音节 |
| 6 | qu 的 u 当辅音算 | qu 算单辅音，前一音节不因它变长 |
| 7 | 双辅音不拆开 | pu-el-la，不是 puel-la |
| 8 | 把 h 算进位置长 | h 不计数 |
| 9 | 古典与教会发音混用 | 选定一套，全程一致 |
| 10 | 不标 macron 也能读 | 长短辨义辨时态，初学必须标 |

## 13. 一页自测

1. *Cicerō* 按古典音怎么读？→ [kikeroː]，三个音节 ki-ke-ro
2. *vīnum* 的第一个音是？→ [w]，不是 [v]
3. *puella* 的重音在哪？为什么？→ 在 -el-，因为 el 是闭音节（后接 ll），位置长
4. *reliquus* 的重音在哪？为什么？→ 在 ré-，因为 qu 算单辅音，li 是短音节
5. *fīlius* 的重音在哪？→ fī-，因为 li 是短音节
6. *arma virumque* 的重音？→ vi-rúm-que
7. *Gallia* 有几个音节？→ 三个：gal-li-a
8. *patientia* 的重音在哪？→ -én-（penult ti 短）
