# 06 · 动词：虚拟式与命令式

> 虚拟式只有 **4 个时态**：现在、未完成、完成、过去完成。前两个挂在现在词干上，后两个挂在完成词干上（被动则为 PPP + sim/essem）。

---

## 1. 虚拟式的骨架

| 时态 | 主动 | 被动 |
|---|---|---|
| 现在 | 现在词干 + **特征元音** + 词尾 | 同左 + 被动词尾 |
| 未完成 | **不定式** + 词尾 | 不定式 + -r 系词尾 |
| 完成 | 完成词干 + **-erī-** + 词尾 | PPP + **sim** |
| 过去完成 | 完成词干 + **-issē-** + 词尾 | PPP + **essem** |

### 1.1 特征元音（现在虚拟式）

| 变位 | 元音 | 1sg | 记忆口诀 |
|---|---|---|---|
| 1 | **ē** | amem | 「1 变位 e」 |
| 2 | **eā** | moneam | mone- + ea |
| 3 | **ā** | regam | reg- + a |
| 3io | **iā** | capiam | capi- + a |
| 4 | **iā** | audiam | audi- + a |

> 口诀：**「一 ē，二 eā，三四 ā」**；混合变位 (capiō) 与第四变位同用 iā。

### 1.2 未完成虚拟式 = 不定式 + 词尾（**永久规则**）

| 变位 | 主动 1sg | 被动 1sg |
|---|---|---|
| 1 | amārem | amārer |
| 2 | monērem | monērer |
| 3 | regerem | regerer |
| 3io | caperem | caperer |
| 4 | audīrem | audīrer |

## 6. 虚拟式的十大用法

| 用法 | 引导词 | 时态 | 例 |
|---|---|---|---|
| 目的 | ut / nē | 现在/未完成（依主句） | *Venit ut vidēret.* 他来是为了看。 |
| 结果 | ut / ut nōn | 现在/未完成 | *Tam bonus est ut omnēs eum ament.* 他好到人人都爱他。 |
| 间接疑问 | 疑问词 | 依序列 | *Rogāvit quid faceret.* 他问该做什么。 |
| 条件（反事实） | sī / nisi | 未完成（现在反）/ 过去完成（过去反） | *Sī adesset, gaudērēmus.* 若他在，我们就会高兴。 |
| cum 从句 | cum | 未完成/过去完成 | *Cum haec dīxisset, abiit.* 他说完这些就走了。 |
| 间接命令 | ut / nē | 现在/未完成 | *Imperāvit ut venīret.* 他命令他来。 |
| 担心 | nē / ut | 现在/未完成 | *Timeō nē veniat.* 我怕他会来。 |
| 特征/描述 | quī + 虚拟 | 现在/未完成 | *Sunt quī putent…* 有人（会）认为…… |
| 让步 | cum / quamvīs / ut | 现在/完成 | *Quamvīs dīves sit…* 尽管他富有…… |
| 愿望 | utinam | 现在（可实现）/未完成（不可能） | *Utinam veniat!* 但愿他来！ |

---

## 7. 时态配合（consecutio temporum）

| 主句时态 | 序列 | 同时/后时 | 先时（已完成） |
|---|---|---|---|
| 现在、将来、将来完成 | **主要序列** | 现在虚拟 | 完成虚拟 |
| 过去（未完成、完成、过去完成、历史现在） | **次要序列** | 未完成虚拟 | 过去完成虚拟 |

> 例：*Dīcit quid fiat*（他说现在发生什么）/ *Dīxit quid fieret*（他说当时发生什么）/ *Dīxit quid factum esset*（他说之前发生了什么）。

## 8. 命令式

### 8.1 现在命令式

| 变位 | 2sg | 2pl |
|---|---|---|
| 1 | amā | amāte |
| 2 | monē | monēte |
| 3 | rege | regite |
| 3io | cape | capite |
| 4 | audī | audīte |

**被动**：2sg = **-re**（amāre, regere, audīre）；2pl = **-minī**（amāminī, regiminī）。

### 8.2 将来命令式（-tō / -tōte / -ntō）

| | 主动 | 被动 |
|---|---|---|
| 2sg | amātō | amātor |
| 3sg | amātō | amātor |
| 2pl | amātōte | amāminī |
| 3pl | amantō | amantor |

（第三/四变位：regitō, reguntō；audītō, audiuntō）

### 8.3 否定命令（禁止）

| 方式 | 形式 | 例 |
|---|---|---|
| 标准 | **nōlī / nōlīte + 不定式** | *Nōlī īre.* 别去。 |
| 正式/诗文 | **nē + 完成虚拟** | *Nē fēceris!* 别做！ |
| 第三人称禁止 | nē + 现在虚拟 | *Nē veniat.* 别让他来。 |

### 8.4 虚拟式命令（劝告式）

| 人称 | 形式 | 例 |
|---|---|---|
| 1pl | 现在虚拟 | *Amēmus!* 我们爱吧！ |
| 3sg/3pl | 现在虚拟 | *Vīvat!* 万岁！ / *Valeant!* 愿他们安好！ |

## 10. 自测

1. *amō* 的现在虚拟被动 3sg？→ amētur
2. *regō* 的未完成虚拟主动 3pl？→ regerent
3. *capiō* 的完成虚拟 1sg 主动？→ cēperim
4. *audiō* 的过去完成虚拟被动 3sg（阳性）？→ audītus esset
5. 「别去」的两种说法？→ Nōlī īre. / Nē īveris.
