# 15 · 构词法与英语派生

> 拉丁词不是一堆孤立的字符串：**词根给意义，前缀给方向，后缀给词性**。
> 学会拆，词汇量从三百变成三千，而且英语里的学术词会自动变透明。

---

## 1. 一个词的解剖

| 成分 | 功能 | 例 |
|---|---|---|
| **前缀** praefīxum | 方向、否定、程度 | dē-（向下）、in-（不／进入）、prō-（向前） |
| **词根** rādīx | 核心意义 | duc- / duct-（引导） |
| **后缀** suffīxum | 词性、抽象化 | -tiō（动作名词）、-tor（施事者）、-bilis（可能） |
| **词尾** | 格、数、性；人称、时态 | -us, -a, -um；-ō, -s, -t |

**三个拆词示例**：

| 词 | 拆解 | 义 |
|---|---|---|
| dēdūcō | dē-（向下）+ dūc-（引）+ -ō | 引下、引出 |
| inimīcus | in-（不）+ amīc-（朋友）+ -us | 不友好的人、敌人 |
| portātiō | portā-（搬）+ -tiō（动作） | 搬运 |

## 2. 前缀表

同化是常态：前缀末尾的辅音会变成与词根首辅音**同部位**的音。下表把同化形一并列出。

| 前缀（含同化形） | 义 | 例 | 英语对应 |
|---|---|---|---|
| ab- / abs- / ā- | 离开 | abdūcō 带走；āmittō 失去 | absent, abstract |
| ad- / ac- / af- / ag- / al- / ap- / ar- / as- / at- | 向、加于 | addūcō 引向；afferō 带来；accēdō 走近 | advance, affect |
| ante- | 前、预先 | antecēdō 先行；antepōnō 置于前 | antecedent |
| circum- | 环绕 | circumdūcō 绕行；circumspectō 环视 | circumvent |
| com- / con- / co- / col- / cor- | 共同、完全 | cōnferō 集中；colloquor 交谈 | collect, connect |
| dē- | 向下、完全、去除 | dēdūcō 引下；dēfendō 防御 | descend, deduct |
| dis- / di- / dif- | 分开、相反 | dīmittō 遣散；differō 拖延、不同 | dismiss, differ |
| ē- / ex- / ef- | 出 | ēdūcō 引出；efferō 拿出 | exit, effect |
| in-（方向） | 进入、在上 | indūcō 引入；impōnō 放上 | include, invade |
| **in-（否定）** | 不 | inimīcus 敌对的；īnfīdus 不忠的 | invisible, injustice |
| inter- | 之间、相互 | interpōnō 插入；interficiō 杀死 | intervene |
| ob- / oc- / of- / op- | 对着、阻碍 | oppōnō 放在对面；occurrō 迎上 | object, oppose |
| per- | 穿过、彻底 | perdūcō 引到底；perficiō 完成 | perfect, pervade |
| post- | 后 | postpōnō 置于后 | postpone |
| prae- | 前、预先 | praedīcō 预言；praepōnō 置于前 | predict, preface |
| prō- | 向前、代替、为了 | prōdūcō 引出；prōsum 有益 | produce, promote |
| re- / red- | 回、再 | redūcō 引回；referō 带回 | reduce, return |
| sē- | 分开、离开 | sēdūcō 引开；sēcernō 分开 | separate, select |
| sub- / suc- / suf- / sup- / sus- | 在下、稍微 | subdūcō 拉起；suscipiō 承担 | submit, support |
| super- | 在上、超过 | superesse 剩余、在上；superfundō 溢出 | superior |
| trāns- | 穿过、越过 | trādūcō 转移；trānseō 穿过 | transfer, transit |
| amb- / ambi- | 四周、双方 | ambīre 环绕；ambigō 犹疑 | ambition, ambiguous |
| ne- / nōn- | 不 | nefās 不义；nequeō 不能 | negative, non- |

> **注意 in- 的两副面孔**：*in-**dūcō*** 是「引入」（方向），*in**ī**quus* 是「不公」（否定）。看词根是否成立：dūcō 是词，īquus 不是。

## 3. 名词后缀

| 后缀 | 义 | 例 | 英语 |
|---|---|---|---|
| -tor / -sor | 做某事的人 | imperātor, victor, cursor | actor, victor |
| -tiō / -siō | 动作、状态 | nātiō, portātiō, missiō | nation, mission |
| -tūdō | 性质 | fortitūdō, multitūdō | fortitude, multitude |
| -tās | 性质、抽象 | libertās, vēritās, cīvitās | verity, city |
| -ia | 状态、集合 | victōria, sapientia, mīlitia | victory, science |
| -ium | 集合、场所、抽象 | imperium, studium, gaudium | —— |
| -mentum | 手段、结果 | monumentum, īnstrūmentum | monument, instrument |
| -men | 手段、结果 | nōmen, flūmen, carmen | —— |
| -culus / -cula | 指小 | rēgulus, rīvulus | molecule, ridicule |
| -ārius | 从事者、场所 | argentārius, aerārius | -ary |
| -īna | 场所、材料 | officīna, medicīna | -ine |
| -ātiō | 动作（-ā- 动词） | portātiō, laudātiō | -ation |

> **-tor 与 -tiō 是一对**：*victor* 是「胜者」，*victōria* 是「胜利」；*imperātor* 是「命令者」，*imperium* 是「命令权」。人—事成对记，效率最高。

## 4. 形容词后缀

| 后缀 | 义 | 例 | 英语 |
|---|---|---|---|
| -ālis / -āris | 属于……的 | nātūrālis, militāris, populāris | natural, military |
| -ārius | 与……有关的 | necessārius, contrārius | necessary |
| -ōsus | 充满……的 | perīculōsus, verbōsus, fōrmōsus | dangerous, verbose |
| -ulentus | 多……的 | turbulentus, opulentus | turbulent, opulent |
| -icus | 属于……的 | cīvicus, mūsicus | civic |
| -īvus | 有……性质的 | captīvus, aestīvus | captive |
| -bilis | 可……的 | amābilis, terribilis, laudābilis | amiable, terrible |
| -ilis | 可……的 | facilis, ūtilis, fragilis | facile, fragile |
| -idus | 处于……状态的 | validus, splendidus, timidus | valid, splendid |

> **-bilis 的构成**：动词词干 + -bilis，如 amā- + -bilis = amābilis「可爱的」。英语 -able / -ible 几乎全部来自这里。

## 5. 动词的构词方式

### 5.1 前缀派生（最常见）

一个 dūcō 可以长成十几个词：

| 复合词 | 义 |
|---|---|
| abdūcō | 带走 |
| addūcō | 引向、说服 |
| dēdūcō | 引下、引出 |
| ēdūcō | 引出、养育 |
| indūcō | 引入、诱导 |
| intrōdūcō | 引入 |
| perdūcō | 引到底、说服 |
| prōdūcō | 引出、产生 |
| redūcō | 引回 |
| subdūcō | 拉起、撤走 |
| trādūcō | 转移、传述 |

> **记一个词根，等于记十个词**。这是拉丁语词汇量增长最快的方式。

### 5.2 后缀派生

| 类型 | 后缀 | 例 |
|---|---|---|
| **反复／频发** | -itāre / -tāre | clāmō → clāmitō 不断喊；dīcō → dictō 反复说 |
| **意愿** | -urīre | pariō → parturiō 想生；ēsuriō 想食 |
| **起始** | -scere | senēscō 变老；crēscō 生长；flōrēscō 开花 |
| 名词 → 动词 | -āre / -ēre / -īre | corōna → corōnāre 加冕；līber → līberāre 解放；mollis → mollīre 软化 |
| 形容词 → 动词 | -āre / -ēre | clārus → clārāre 使明亮；clāreō 发亮 |

## 6. 音变：为什么复合词长得不像原词

| 现象 | 规则 | 例 |
|---|---|---|
| **元音弱化** | 复合词中短元音变 i / e | faciō → perficiō；capiō → accipiō；caedō → occīdō；teneō → contineō |
| **同化** | 前缀末辅音变得与词根同部位 | ad- + ferō → afferō；in- + legō → intellegō；com- + loquor → colloquor |
| **脱落** | 前缀元音在元音前脱落 | co- + eō → coeō；dē- + habeō → dēbeō |
| **增音** | prō- 在元音前加 d | prōsum → prōdesse, prōdest, prōdī |
| **rhotacism** | 元音间的 s 变 r | flōs / flōris；iūs / iūris；es-se 与 er-am 同源 |
| **简化** | 重复音节合并 | nēmō ← nē + homō |

> 看到 *intellegō* 不要以为它是 irregular：它是 in- + legō，前缀 n 被 l 同化成 l。同类还有 *intelligō* 的异体拼法。

## 8. 英语派生规律

| 英语后缀 | 来自拉丁 | 例 |
|---|---|---|
| -tion / -sion | -tiō / -siō | nation, action, mission |
| -ment | -mentum | monument, argument |
| -ous | -ōsus | dangerous, famous |
| -ity | -tās（经法语 -ité） | verity, city |
| -al | -ālis | natural, legal |
| -ar | -āris | military, similar |
| -ary | -ārius | necessary, primary |
| -ate | -ātus | create, ornate |
| -fy / -ify | -ficāre | verify, amplify |
| -ble | -bilis | visible, possible |
| -ent | -ēns / -entis | patient, current |
| -ant | -āns / -antis | constant, important |
| -ine | -īnus | marine, divine |
| -ic | -icus | civic, public |

> **英语词往往经过法语「磨损」**：拉丁 *portātiō* → 法语 *portion* → 英语 *portion*。所以拼写对不上不奇怪，看词根即可。

## 9. 长词拆解四步法

1. **看后缀定词性**：-tion 名词、-ous 形容词、-fy 动词。
2. **剥前缀**：in-, con-, re-, trans-, sub-…
3. **找词根**：dict, duct, spect, port…
4. **用「前缀方向 + 词根义 + 后缀词性」组义**。

| 英语词 | 拆解 | 字面义 → 实际义 |
|---|---|---|
| circumspect | circum（环）+ spect（看） | 环顾 → 谨慎 |
| prescription | prae（前）+ scrīb（写）+ -tion | 预先写 → 处方 |
| manuscript | manū（手）+ scrīptus（写） | 手写 → 手稿 |
| benevolent | bene（好）+ volent（愿） | 好意 → 仁慈 |
| malevolent | male（坏）+ volent（愿） | 恶意 → 恶毒 |
| verdict | vērum（真）+ dictum（说） | 说真 → 裁决 |
| aqueduct | aquae（水）+ ductus（引） | 引水 → 引水道 |
| manufacture | manū（手）+ factūra（做） | 手做 → 制造 |
| expedition | ex（出）+ ped（脚） | 走出去 → 远征 |
| unanimus | ūnus（一）+ animus（心） | 一心 → 一致 |

## 10. 易错点

| # | 坑 | 正解 |
|---|---|---|
| 1 | 把 in- 一律当否定 | in- 也可表「进入」：indūcō 是引入，不是「不引」 |
| 2 | 复合词按原词拼写找 | 有同化与弱化：adferō → afferō；perfaciō → perficiō |
| 3 | 认为 -tor 只指人 | 也可指工具：motor, vector |
| 4 | 把 -tās 与 -tūdō 混 | 二者都表性质，但搭配固定：fortitūdō、liber…tās |
| 5 | 英语拼写与拉丁一一对应 | 多经法语转写，形式常变 |
| 6 | 见 -bilis 就当「能」 | 也可表「值得」：amābilis 可爱、laudābilis 可嘉 |
| 7 | rhotacism 不认识 | flōs/flōris、iūs/iūris 是同一词根 |
| 8 | 把 prōdesse 当 irregular | prō- 在元音前加 d，是规则变化 |

## 11. 一页自测

1. *dēdūcō* 怎么拆？→ dē-（向下）+ dūcō（引）→ 引下
2. *inimīcus* 的 in- 是哪种？→ 否定（不友好）
3. *indūcō* 的 in- 呢？→ 方向（引入）
4. *perficiō* 为什么不是 *perfaciō*？→ 复合词元音弱化 a → i
5. *afferre* 来自哪两个部分？→ ad- + ferre，d 同化为 f
6. *fortitūdō* 与 *fortitās* 哪个对？→ fortitūdō
7. *-bilis* 在 *amābilis* 中表什么？→ 值得爱／可爱
8. *manuscript* 的字面义？→ 手写之物
9. *verdict* 的两个成分？→ vērum（真）+ dictum（说）
10. *prōdest* 为什么有 d？→ prō- 在元音前增音
