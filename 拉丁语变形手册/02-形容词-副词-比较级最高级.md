# 02 · 形容词、副词、比较级与最高级

> 形容词必须与所修饰名词**同格、同数、同性**（仅格数性一致，词尾各自按自己的变格类走）。
> 三类形容词：**第一/二变格型**、**第三变格型**、**-īus 型（代名形容词）**。

---

## 1. 第一/二变格形容词

### 1.1 bonus, -a, -um 好的

| | 阳性 | 阴性 | 中性 |
|---|---|---|---|
| Sg N | bonus | bona | bonum |
| G | bonī | bonae | bonī |
| D | bonō | bonae | bonō |
| Acc | bonum | bonam | bonum |
| Abl | bonō | bonā | bonō |
| Pl N | bonī | bonae | bona |
| G | bonōrum | bonārum | bonōrum |
| D | bonīs | bonīs | bonīs |
| Acc | bonōs | bonās | bona |
| Abl | bonīs | bonīs | bonīs |

### 1.2 词干带 -e- 与丢 -e- 两类

| 类型 | 例 | 变化 |
|---|---|---|
| 保留 e | **miser, misera, miserum** 可怜的 | 全表保留 e |
| 丢失 e | **pulcher, pulchra, pulchrum** 美的 | 除阳性主格外丢 e（pulchrī, pulchrō…） |
| 丢失 e | **sacer, sacra, sacrum** 神圣的 | 同上 |
| -er 但有 e | **liber, libera, liberum** 自由的 | 保留 e（与名词 liber 书 不同！） |

## 2. 第三变格形容词

三种结尾类型：

| 类型 | 主格（m./f./n.） | 例 |
|---|---|---|
| 三尾 | -er, -is, -e | celer, celeris, celere 快的 |
| 二尾 | -is, -is, -e | fortis, fortis, forte 勇敢的 |
| 一尾 | -s / -x / -r（m./f./n. 同形） | audāx, audācis 大胆的；vetus, veteris 老的 |

### 2.1 二尾型：fortis, -e 勇敢的

| | 阳/阴 | 中性 |
|---|---|---|
| Sg N | fortis | forte |
| G | fortis | fortis |
| D | fortī | fortī |
| Acc | fortem | forte |
| Abl | fortī | fortī |
| Pl N | fortēs | fortia |
| G | fortium | fortium |
| D | fortibus | fortibus |
| Acc | fortēs | fortia |
| Abl | fortibus | fortibus |

### 2.2 一尾型：audāx, audācis 大胆的

| | 阳/阴 | 中性 |
|---|---|---|
| Sg N | audāx | audāx |
| G | audācis | audācis |
| D | audācī | audācī |
| Acc | audācem | audāx |
| Abl | audācī | audācī |
| Pl N | audācēs | audācia |
| G | audācium | audācium |
| D | audācibus | audācibus |
| Acc | audācēs | audācia |
| Abl | audācibus | audācibus |

> **第三变格形容词三标志**：夺格单数 **-ī**、属格复数 **-ium**、中性复数 **-ia**。
> 例外：**vetus**（老）除属格复数 veterum 外，其余近辅音词干；**dīves**（富）属格 dīvitis；**pauper** 属格 pauperis。

## 3. -īus 型（代名形容词）

这类形容词的**属格单数一律 -īus**，**与格单数一律 -ī**，其余按第一/二变格。

| 词 | 义 |
|---|---|
| alius, alia, aliud | 别的（属格 alīus，古典常以 alterīus 代之） |
| alter, altera, alterum | 两者中的另一个 |
| ūllus, -a, -um | 任何一个 |
| nūllus, -a, -um | 没有 |
| sōlus, -a, -um | 唯一的 |
| tōtus, -a, -um | 整个的 |
| ūnus, -a, -um | 一个 |
| uter, utra, utrum | 两者中的哪一个 |
| neuter, neutra, neutrum | 两者都不 |
| ipse, ipsa, ipsum | 自己（代词，同型） |

| | alius | alter |
|---|---|---|
| G sg | alīus | alterīus |
| D sg | aliī | alterī |
| 其余 | 同 bonus | 同 bonus |

- **alius 的属格**：标准形式是 **alīus**，但古典作家普遍改用 **alterīus**（alter 的属格）以避免歧义，两种都对；与格一律 **aliī**；复数中性 **alia**。
- **tōtus** 的属格 **tōtīus**，与格 **tōtī**。

## 4. 比较级（Comparative）

### 4.1 构成

> **词干 + -ior（阳/阴）/ -ius（中性）**，属格 **-iōris**。

| 原级 | 比较级 |
|---|---|
| altus 高 | altior, altius |
| fortis 勇敢 | fortior, fortius |
| audāx 大胆 | audācior, audācius |
| fēlīx 幸运 | fēlīcior, fēlīcius |

### 4.2 比较级变格（第三变格，辅音词干）

| | 阳/阴 | 中性 |
|---|---|---|
| Sg N | altior | altius |
| G | altiōris | altiōris |
| D | altiōrī | altiōrī |
| Acc | altiōrem | altius |
| Abl | altiōre | altiōre |
| Pl N | altiōrēs | altiōra |
| G | altiōrum | altiōrum |
| D | altiōribus | altiōribus |
| Acc | altiōrēs | altiōra |
| Abl | altiōribus | altiōribus |

### 4.3 最高级（Superlative）

> **词干 + -issimus, -a, -um**（第一/二变格）。

| 原级 | 最高级 |
|---|---|
| altus | altissimus |
| fortis | fortissimus |
| audāx | audācissimus |

### 4.4 特殊拼写规则

| 原级词尾 | 变化 | 例 |
|---|---|---|
| -er | 加 **-rimus** | miser → miserrimus；pulcher → pulcherrimus；ācer → ācerrimus |
| -ilis | 加 **-limus** | facilis → facillimus；difficilis → difficillimus；similis → simillimus；humilis → humillimus；gracilis → gracillimus |
| -dicus / -ficus / -volus | 变 **-entior / -entissimus** | magnificus → magnificentior, magnificentissimus；maledicus → maledīcentior |
| 借他类词干 | 另记 | 无 |

### 4.5 不规则比较等级（必背）

| 原级 | 比较级 | 最高级 |
|---|---|---|
| bonus 好 | melior, melius | optimus |
| malus 坏 | peior, peius | pessimus |
| magnus 大 | maior, maius | maximus |
| parvus 小 | minor, minus | minimus |
| multus 多 | plūs（n.；属格 plūris） | plūrimus |
| vetus 老 | vetustior | vetustissimus / veterrimus |
| senex 老人 | senior | —（用 maximus nātū） |
| iuvenis 青年 | iūnior | —（用 minimus nātū） |
| dīves 富 | dītior | dītissimus |
| pauper 穷 | pauperior | pauperrimus |
| frūgī 节俭 | frūgālior | frūgālissimus |
| dexter 右 | dexterior | dextimus |
| potis 能 | potior | potissimus |
| sacer 神圣 | sacrior | sacerrimus |

> **plūs** 只有中性单数/复数：plūs, plūris, plūrī, plūs, plūre；plūra, plūrium, plūribus。

### 4.6 比较级用法

| 用法 | 结构 | 例 |
|---|---|---|
| 比……更 | 比较级 + **quam** + 同格 | altior **quam** frāter |
| 比……更（省 quam） | 比较级 + **夺格** | altior **frātre** |
| 大多少 | 比较级 + 度量夺格 | **multō** altior（高得多） |
| 太…… | 比较级 + **quam ut** / nimis | altior **quam ut** trānseat |
| 宁可……而不 | 比较级 + quam | mālō morī quam servīre |

> quam 后必须与前面**同格**；夺格比较只用于「比较的第二项」是该格时，且句中不能有歧义。

### 4.7 最高级用法

| 用法 | 结构 | 例 |
|---|---|---|
| 最……的 | 最高级 + 属格（部分属格） | **omnium** fortissimus |
| 在……之中 | 最高级 + ex / dē + 夺格 | fortissimus **ex** Rōmānīs |
| 尽可能…… | **quam** + 最高级 | **quam** fortissimus |
| 每一个最……的 | 最高级 + **quisque** | optimus **quisque**（每一个最好的人） |

### 4.8 无比较级时

用 **magis / maximē** + 原级：magis idōneus（更合适）、maximē idōneus。

## 5. 副词

### 5.1 构成

| 形容词类型 | 规则 | 例 |
|---|---|---|
| 第一/二变格 | 词干 + **-ē** | cārus → cārē；pulcher → pulchrē；miser → miserē |
| 第三变格 | 词干 + **-iter** | fortis → fortiter；audāx → audācter；celer → celeriter |
| 少数 | 词干 + **-ō** | citō（快）、falsō、subitō、meritō |
| 特殊 | 另记 | bonus → bene；malus → male；facilis → facile；difficilis → difficulter |

### 5.2 副词比较级与最高级

| 原级 | 比较级 | 最高级 |
|---|---|---|
| fortiter 勇敢地 | fortius | fortissimē |
| cārē 珍贵地 | cārius | cārissimē |
| audācter 大胆地 | audācius | audācissimē |
| **bene** 好 | **melius** | **optimē** |
| **male** 坏 | **peius** | **pessimē** |
| **magnopere** 很 | **magis** | **maximē** |
| **multum** 多 | **plūs** | **plūrimum** |
| **saepe** 常 | **saepius** | **saepissimē** |
| **prope** 近 | **propius** | **proximē** |
| **diū** 久 | **diūtius** | **diūtissimē** |
| **facile** 容易地 | **facilius** | **facillimē** |
| **nūper** 最近 | ——（基本不用） | **nūperrimē** |
| **parum** 太少 | **minus** | **minimē** |

### 5.3 副词比较级用法

- 比较级中性单数即副词比较级：**fortius pugnat**（他打得更勇）。
- 比较对象：**fortius quam ille** 或 **fortius illō**。
- 最高级副词：**fortissimē**（最勇地）。
- **quam** + 最高级副词 = 尽可能……地：quam celerrimē（尽可能快）。

## 7. 一页自测

1. *bonus* 的阴性属格复数？→ bonārum
2. *fortis* 的中性复数主格？→ fortia
3. *audāx* 的夺格单数？→ audācī
4. *magnus* 的比较级中性？→ maius
5. *facilis* 的最高级？→ facillimus
6. *bene* 的比较级与最高级？→ melius / optimē
7. 「比兄弟更高」两种说法？→ altior quam frāter / altior frātre
